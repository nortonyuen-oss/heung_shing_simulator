# 香港游泳池佔格研究

研究日期：2026-10-18。沿用本批資產每格20×20米，即400平方米。

最新選定：用戶已選擇先做3×3格簡約版。成品為 `Models/swimmingPool/sp_simple3x3_v1.png`，流程及原圖在 `scripts/source-art/swimmingPool/v1/`。下列4×4內容保留作較大型版本的研究候選。

目前美術選擇：用戶已接受籃球場v2，可與街市v3一同安排加入遊戲；本輪先研究泳池尺寸，尚未生成泳池或進行這兩項資產的runtime接入。

## 官方資料

- 康文署場館資料：深水埗公園、荔枝角公園的主池為50×25米，訓練池為25×11米；柴灣、李鄭屋等主池為50×21米。因此不把所有香港主池一律當作50×25米。來源：[康文署公眾游泳池資料](https://www.lcsd.gov.hk/clpss/tc/webApp/Swimming.do)。
- 小型例子：青衣西南游泳池設25×15米室內訓練池及更衣設施，泳池在綜合大樓內，不能把整座大樓用地都算作單一泳池用地。來源：[康文署](https://www.lcsd.gov.hk/clpss/tc/webApp/Swimming.do?swpId=44)。
- 屯門西北游泳池場館約1.5公頃，按面積相當於37.5格。來源：[政府新聞公報](https://www.info.gov.hk/gia/general/201306/29/P201306280456.htm)。
- 觀塘游泳池場館約18,000平方米，按面積相當於45格。來源：[政府新聞公報](https://www.info.gov.hk/gia/general/201303/30/P201303280583.htm)。這兩個例子不是全港泳池的面積上下限。

## 遊戲模型建議（設計估算，並非官方用地標準）

| 用地 | 實際邊長 | 面積 | 配置方向 |
| --- | --- | --- | --- |

| 4×4格 | 80×80米 | 6,400平方米 | 建議：精簡公眾泳池，主池＋訓練池＋兒童池＋更衣室 |
| 約38–45格 | 視地盤形狀 | 約15,000–18,000平方米 | 上述大型泳池場館例子的面積級別；不是4×4格的縮放版本 |

單計50×25米水面是1,250平方米，相當於2.5×1.25個格距。整個場館還要預留池邊、入口、更衣、淋浴、機房及維修空間；不可用水面面積代替地盤面積。

## 4×4格可行的初步佈局

以下是80×80米內的平面設計候選，並未獲用戶選定。池邊每側暫預3米是本次設計假設，並非引述法定要求。

- 主池：x=5..55、y=35..60（50×25米）；連池邊範圍x=2..58、y=32..63。
- 訓練池：x=5..30、y=13..24（25×11米）；連池邊x=2..33、y=10..27。
- 小型兒童池預留：x=39..51、y=14..24（12×10米）；連池邊x=36..54、y=11..27。
- 單／兩層更衣及入口附屬樓：x=63..77、y=12..65。
- 小看台或遮蔭長廊預留：x=5..55、y=66..74。
- 其餘用作入口、服務機房、步道、圍欄及綠化；不堆入大型跳水池或第二個50米池。

美術方向候選：舊市政局／屋邨旁的露天公眾泳池，米白或淺色低層附屬樓、青綠欄杆、淺色防滑池邊、救生員高椅、簡單遮蔭設施。生成前先畫超幼灰色1:2格線及直線幾何；保留籃球場v2的教訓，禁止以局部非線性扭曲去匹配控制點。
