# 香港全境接回原遊戲

香港全境現在是原遊戲的地圖後端。主選單「開新城市 → 香港全境」在既有 Phaser Scene 開始遊戲，沒有頁面切換、iframe 或第二套遊戲 HUD。「載入存檔」同時列出普通城市及全境城市；移除主選單的獨立全境測試按鈕與對話框。舊 /world/index.html 連結轉到共用遊戲入口。/world/benchmark.html 僅供歷史效能與串流測試使用，沒有主選單入口。

## 遊戲與地圖資料

- 原工具欄、建築目錄、解鎖、檢視器、日曆、經濟、政策、需求、人口、電力、服務及運輸模組繼續執行原遊戲規則，不再以 WorldSimulation 的試驗規則取代。
- WorldGameHost 把 3187×2400 座標接入既有場景。原遊戲的二維格存取使用稀疏相容層：只有寫入格持有值，讀取一列不會配置一條 3187 格的 backing array。
- 不可變地形沿用校驗過的 terrain packs、32×32 renderer、64×64 storage、九個詳細區塊上限與 3ms mount/unmount 工作預算。LOD 在詳細地形讀取期間保留。
- 城市計算遍歷已建設、分區、服務及網絡格，不使用探索範圍的巨型包圍矩形。電力、道路及成長不以圖片是否掛載決定實體是否存在。
- 原 buildingData 與 footprint index 是建築的持久資料。buildingSprites Map 的 has 查詢包含邏輯佔地；需要原 sprite 方法的改建／拆卸會按需取得圖片。視窗離開後圖片可銷毀，資料保持。
- 道路、分區、樹木、雜物、巴士站、電線、橋及地鐵路軌仍使用原有素材，按詳細區域重新建立圖片。城市小地圖沿用原視窗、拖動及旋轉操作，底圖使用全境 LOD；覆蓋圖以固定 256×256 畫布取樣全境。
- 夜間遠郊暗化場裁切至目前 96×96 區域，保留原夜景效果，不建立全境 raster。

## 存檔與兼容

世界 v2 格式新增可選 game v1 欄位，存放原城市規則的 city、buildingData、稀疏修改 layers、樹木／橋／巴士站、電力集合、道路素材與原運輸 expansion 狀態。地形 base identity、原世界 chunks/entities、storageRevision、原子交易、寫入鎖及上一版備份仍由既有世界儲存層處理。普通城市繼續使用原 v15 格式與原 API。

game 是整合後原玩法的權威狀態；原試驗 chunks/entities 保留作來源與備份。此版本 game 以完整稀疏快照寫入世界 header，並非把每個原遊戲欄位逐一改寫成 chunk 增量。它不序列化全境格，但大規模已建城市的存檔成本仍隨已修改資料增加；Phase 5 簡化模擬的效能數字不能視為本次完整玩法的驗收數字。

- 儲存、另存、每 15 秒自動儲存、下載及匯入走原遊戲入口，按格式分流。
- 「載入存檔」可以下載目前與上一版世界備份。世界備份匯入為獨立新 slot，不覆蓋來源。
- 舊 v2 試驗存檔的地形、分區、道路、兩款建築、橋及路軌轉成原遊戲資料，原始試驗資料保留。試驗版的示意車服務仍存於原 simulation 欄位，不會自動變成原遊戲的巴士／地鐵路線；正式運輸使用原有站點、車輛及營運規則。
- 儲存失敗時不關閉目前全境；原本普通城市檔與使用者未提交修改不作遷移。

## 驗證

新增稀疏列無密集 backing array、遠距寫入、明確零值、世界 checkpoint／portable round trip 及損壞座標拒絕測試。

scripts/smoke-world-integration.js 實際經主選單開城，以原工具起路、分區及起屋，驗證遠處圖片卸載但實體佔地保留，再執行原電力／服務／交通／經濟，旋轉、存檔、重載及共用載入選單。scripts/smoke-world-release.js 的 menu scenario 同時覆蓋 IndexedDB 與 SQLite。Safari 與 Electron 驗收腳本亦已切換到共用場景。

## 效能修正與離屏摘要（使用者追加要求）

CPU profile 證實原舞獅 getLionDanceLayoutExtras 每次掃 mapData.length × row.length 的 765 萬格，是預設 1900 年開城停滯的主因。舞獅、中秋路線及盂蘭路邊效果改查目前詳細區域的已建道路索引；盂蘭郊野效果只查鏡頭附近，不再配置全境 prefix-sum raster。裝飾船舶尋路亦加上 8192 次搜尋上限。

同一 Chrome 開城 CPU 採樣（約 8 秒）的修正前後：10 → 461 個畫面幀；p95 333.4 → 16.8ms，p99 修正後 33.4ms。屬開發機上的空城驗證，不能當成 iPhone 或成熟大城成績。原始 CPU profile 與報告在 test-results/world-integration（不提交產物）。

WorldChunkSummaryTable 是以 64×64 storage chunk 為鍵的稀疏表，每列只有 chunkId、人口、電力供應／消耗、每月稅金／當地設施支出、住商工需求。只有實際修改、分區或建設過的區域加入；瀏覽未發展區域不建列。電力總供需從摘要累加，跨區連通仍使用稀疏道路／電網資料。稅務及整體城市帳目仍由原遊戲結算，政策、貸款等城市層支出不重複分攤入區塊。

離屏區域不跑逐格成長、改建、衰退或樹木／雜物更新；模擬讀取建築亦不再自動建立離屏圖片。建築及道路的持久資料繼續保留，避免返回區域時遺失；這些資料和摘要表用途不同。沒有把所有實體明細從 RAM 改為分頁資料庫；先修實測熱點，保留原玩法相容性。

最終補上兩個切換／存檔保護：手動及自動存檔共用同一 writer，等待期間的新修改會再寫一次，避免兩個呼叫互相提高 revision 而無限重試；離開世界時還原普通城市的 256×256 地形所有權及場景指標，避免載入同大小舊城時只剩串流道路圖片。新增並發存檔測試，完整測試現為 1,360 項通過，世界測試包含新增整合案例。

最後一輪空城測試（修正空白區裝飾掃描與未修改地形捷徑後）：28 個區域逐一等到載入完成，maxMounted=9、errors=0、摘要維持 1 筆；GC 後 JS heap 53,241,828 → 57,623,615 bytes；幀 p95 16.8ms、p99 83.4ms，detail-load p95 312.8ms（上一輪未加捷徑為 2099.4ms）。跳區仍有少量尖峰，未宣稱成熟大城或 iPhone 能維持同等幀時間。

Safari 18.6 的共用場景開城、跨區、儲存重載及共用讀檔選單通過，無 frame error，maxMounted=9。另修正地形未解碼時還原 height=0 被當成無修改的問題，保證夷平存檔在解碼後仍維持平地；普通城市存檔中的 buildingData 轉成一般物件，保留 Worker 序列化，避免世界模式的 Proxy 令原城市退回主執行緒。

提交前驗收為完整 1,362 項測試通過。建設修改維持 1.2 秒防抖自動儲存，時鐘等背景狀態每 15 秒更新；普通城市的 Worker 序列化亦以實際瀏覽器測試確認。直接開啟／重載世界連結時跳過示範城市及臨時 65,536 張地形圖片的預載，主選單仍沿用原有展示城市。

另加入建設資料檢查：尚未有詳細地形的操作不扣款／不落盤，觸控預覽與確認同樣重驗；道路建設保留原地面高度，解碼快取逐出後邏輯高度仍不變。未知地形不會被補成永久 height=0。完整 28 區載入的空城測試，摘要仍 1 筆、maxMounted=9、快取守上限，GC 後 heap 約 53→58MB；指標只代表這個測試場景。

## 海岸線保真修正（香港仔、鴨脷洲）

主畫面超出九塊詳細地形後，原先只顯示 1024px 全港 Overview。把全港縮至同一張圖再放大，會抹去香港仔避風塘、鴨脷洲及鴨脷排的細小海岸／水道，造成可見地理失真。不是改用另一份地形來源。

現以同一份完整地形，在建置時為 130 個 256×256 地區各預製四方向 1024px Regional LOD。主畫面只載入視野需要的最多四張，兩個讀取併發，decoded cache 8 MiB、Phaser texture 8 MiB 上限；換區及離開城市時釋放圖片、texture。這些是靜態低細節底圖，不建立額外詳細地形、模擬資料或摘要記錄。原 Overview 保留作未快取／網絡失敗時的後備，小地圖的 512px Local Cache 保持原有 4 MiB 預算。

新城恢復 `getHkTerritoryDefaultStart()` 的原起點 col=1593、row=1200，不再使用開發試驗區 col=1584、row=1760（相隔約 11.2 km）。已保存的鏡頭位置及建設座標直接保留。

原始 `hk-terrain-tiles.js` 與串流改造前的 SHA-256 相同。資產驗證現在逐一檢查全部 7,648,800 格的原始碼是否位於正確世界座標，避免 pack 內容有效但區域被放錯。舊全境逐 256 格整理與目前全域整理的全港比對，只在原分區邊緣出現 104 格高度差（最多一級）、59 格類型差、15 格海陸差；香港仔、鴨脷洲的海岸輪廓一致。

`npm run audit:world-coastline` 預設核對香港仔、鴨脷洲的 256×256 範圍（col=1588、row=1693），也可加地區 id。四方向各 65,536 格的海陸分類與詳細地形一致，錯誤為零；先前 Overview 在方向零的同區取樣有 1,245 格差異。此檢查針對原全境 20m 格中心，不宣稱與各地區不同 5m 起算格的裁切圖逐格相同，亦不是實際測量精度保證。

本次驗收：完整 1,366 項、世界 63 項通過，Safari 共用場景及 Chrome 28 區跳轉／存檔重載通過。區域底圖 errors=0，GC 後 JS heap 約 54→58 MB，摘要維持兩筆實際建設區域，沒有因探索新增。獨立 Chrome 空城開城採樣約八秒：466 幀、p95 16.8ms、p99 33.3ms；跨區壓測另有載入尖峰，不能套用這個穩定數字，亦未作新 iPhone 計時。

後續修正了原遊戲小地圖的長方形逆投影誤跳，加入全境／區域與手機導航，並將密集道路的 GPU stencil 批次中斷修正、舊全港 RLE 按需讀取及 Chunk 索引接回原遊戲。實際點擊與 48,000 格道路測量見 [定位與載入紀錄](world-streaming-loading.md)。
