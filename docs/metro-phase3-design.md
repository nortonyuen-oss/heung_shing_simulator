# 地鐵 — 第三期設計 v0.1（地面同高架）

日期：2026-11-05。狀態：Norton 已決定（§8），開始做。第一期：`metro-design.md`；第二期：`metro-phase2-design.md`；
路軌格：`railway-track-system.md`。

## 1. 目標

第一、二期嘅地鐵全部喺地底，地圖上只見到出入口。第三期令列車喺地圖上行：玩家起路軌，列車喺上面跑，
好似示範環（2026-11-04）咁。

已經有（已 commit）：
- 雙軌路軌格（一格一條綫，兩條路軌相距 4 米），直路、細彎、分岔、交叉；`railway-track.js`。
- 大彎：2 × 2 格，半徑 30 米（`RAILWAY_TRACK_LARGE_CURVES`）。
- 列車示範：Norton 嘅 `MTrains` 車頭卡（每幅一頭車頭、一頭接駁位），中間卡由兩幅拼出；斜升方向用斜落翻轉；
  按紅色腰綫拉正到 0.5（`scripts/metro-train-demo/`，未入遊戲）。

## 2. 起路軌

- 新工具「路軌」：好似起路咁拖，沿地圖橫或直方向。拖到轉 90° 嘅位置，自動放一個 2 × 2 大彎
  （四格都要空地）。
- 只可以起喺平地、空地（冇建築、冇路）。斜坡、水面同過馬路見 §4。
- 費用：每格 $500（地底隧道每格 $300，但地面要買地、起路基），每月每格保養 $2。
- 推土機拆路軌：有地鐵綫用緊嘅格唔准拆（同第一期車站一樣）。

## 3. 地面站

- 月台喺直路上，長度跟列車：四卡車 90 米，即係 **5 格**直路。月台兩邊各一，中間係雙軌，上面有上蓋。
- 站嘅乘客、車費、覆蓋範圍、物業收入同第一、二期地底站一樣，只係位置喺路軌上，唔使另外起出入口。
- 美術：月台（灰色地磚、黃色警示綫）同上蓋（玻璃頂、鋼柱）可以好似路軌咁用程式畫，跟地鐵站出入口嘅顏色；
  或者 Norton 出圖。

## 4. 過馬路同地形

- 港鐵冇平交道。兩個做法：
  - **高架**：路軌行喺橋墩上面，跨過馬路同建築。高架格 = 路軌格 + 混凝土橋面 + 橋墩，同樣用程式畫。
    上落高架要斜坡（大約 3 格）。
  - **平交道**：路軌直接過馬路，好似輕鐵。簡單，但唔似港鐵。
- 水面：第一期嘅地底隧道已經可以過海，地面路軌唔過水。

## 5. 列車

- 列車喺地面同高架路段畫出嚟，沿路軌行，靠左行（港鐵）。速度、班次、載客同第一期一樣，時鐘計位置。
- 每列四卡：頭卡、兩卡中間、尾卡。按行車方向揀圖（車頭向前）。
- 8 個方向：斜升、斜落、橫、直各兩邊。大彎中間（45°）會用橫或直向圖；示範時直向車廂睇落比斜向高，要調。
- 列車放 `Models/metroTrain/`（處理後），原圖搬去 `scripts/source-art/subwayStation/original/MTrains/`。

## 6. 同第一期地底綫點樣夾埋

- **做法 A：一條綫可以一段地底、一段地面。** 兩個站之間，如果有路軌連住就行地面，冇就掘直綫隧道。
  地底同地面之間要隧道口（斜坡落地底，要一款新圖）。最似真港鐵（觀塘綫、荃灣綫都係咁）。
- **做法 B：第三期先做獨立地面綫。** 一條綫全部地底或者全部地面，唔混合。簡單好多，隧道口留第四期。

## 7. 存檔同測試

- 存檔：`metro.tracks`（每格嘅 TrackBits 同大彎）、`metro.surfaceStations`；運輸 schema 唔使升級。
- 測試：拖路軌揀格（直路、大彎、唔准轉 45°）、月台長度、列車沿路軌嘅位置同方向、拆路軌限制。

## 8. 已決定（Norton，2026-11-05）

1. 第三期做獨立地面綫：一條綫全部地底或者全部地面，唔混合；隧道口留第四期。
2. 過馬路用高架（港鐵冇平交道）。
3. 月台同高架用程式畫，同路軌風格一致。
4. 大彎 45° 嘅直向、橫向車廂：試過縮到同斜向一樣高，反而唔好睇（Norton，2026-11-05），保持原本大細。
