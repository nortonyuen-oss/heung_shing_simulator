# 地鐵 — 第一期設計 v0.1（地底）

日期：2026-11-03。狀態：Norton 已決定（§9），開始做第一期。

## 1. 目標

玩家喺運輸公司（運輸模式）入面起地鐵：喺地面起車站，喺站與站之間拉線，買列車，收車費。列車喺地底行，
地面唔使畫路軌同列車，所以第一期唔使處理路面、地形、橋、高架。地鐵係運輸公司第三種交通工具，
同巴士、天星小輪共用公司資金、路線表、月結（`transport-ttd-spec.md`、`star-ferry-design.md`）。

第一期唔做：高架同地面路段、轉車站（兩條線共用一個站）、輕鐵、電車、列車喺地面嘅美術。

## 2. 車站

- **地面**：一個出入口建築，佔 **1 × 1 格**（20 米，大約港鐵一個出口連上蓋嘅大小）。要起喺平地、
  隔籬有路（行人由路口入站）。出入口向住條路，好似巴士車廠咁揀方向。
- **地底**：大堂同月台喺地底，唔使畫；車站喺地底佔幾多唔影響地面。
- **費用**：$15,000 起一個站（一個巴士車廠 $4,000，地鐵站要挖），每月保養 $100。
- **覆蓋範圍**：站嘅 **10 格**（200 米）內嘅住宅同工作地點會搭（巴士站 5 格；搭地鐵肯行遠啲）。
- **清拆**：推土機拆站；有路線經過嘅站唔可以拆，要先由路線移走。

## 3. 路線

- 一條線係 2 個或以上車站嘅次序表，喺運輸模式「地鐵」分頁逐個撳站加入（同渡輪航線一樣嘅次序編輯）。
- 站與站之間嘅隧道係直線，喺地底，唔理路面、建築、地形；**可以穿越海底**（過海鐵路），海底段貴啲。
- **起隧道費**：每格陸地 $300、每格海 $700，加站時即付。拆線唔退錢。
- 每條線有名同顏色（預設跟港鐵：荃灣綫紅、港島綫藍、觀塘綫綠、東涌綫橙……），喺運輸模式用彩色線顯示。
- 每條線最多 12 個站；全公司最多 8 條線。

## 4. 列車

| | |
|---|---|
| 售價 | $5,000（約 18 架雙層巴士） |
| 載客 | 1,500 人一班（巴士 70、天星 400） |
| 速度 | 每顯示分鐘 4 格（巴士 1.33、天星 1），站與站直線 |
| 停站 | 每站 1 分鐘 |
| 保養 | 每月 $150，加每格行駛成本 |
| 每線上限 | 10 列 |

- 列車位置由時鐘計（同天星小輪一樣），唔儲存移動狀態，重開或者快轉都唔會走位。
- 列車喺地底，地圖上睇唔到；運輸模式入面喺路線上畫小點，顯示每班車喺邊。
- 營運時間 06:00–01:00；八號風球照開（地底唔受影響），但地面出入口附近嘅人會少啲。

## 5. 乘客同收入

- **邊個搭**：同渡輪碼頭一樣，每個站有一條隊，按巴士站嘅上班曲線逐個鐘加人：
  覆蓋範圍內嘅住宅，乘數高過巴士站（地鐵快，肯行遠啲）。站同站之間按覆蓋大小分配落車。
- **車費**：按距離（似港鐵）：基本 $0.05 + 每格 $0.002（公司元），喺「車費」滑桿可以調。
- **城市效果**：沿用巴士嘅機制，但更強：
  - 站附近地價上升（最多 +15%，巴士 +8%），由站向外遞減。
  - 覆蓋範圍內嘅住宅轉搭地鐵，路面車流減少（最多 −40%，巴士 −25%）。
  - 覆蓋到嘅商業同住宅：需求同快樂度加成。
- **月結**：車費入公司，扣列車保養、行駛成本同車站保養；每條線有每月記錄（同巴士、渡輪一樣）。
- **回本**：一條三個站嘅過海綫（試玩城市）大約一年回本；雙層巴士要 17 個月。第一次試玩用 $6,000／$120／$2,000 嘅價錢，四、五個月就回本，太快，所以加咗價。

## 6. 解鎖

運輸公司已經成立，加人口達 **30,000**（巴士 3,000）。解鎖時討論區出一篇「地鐵規劃」帖。

### 6.1 地下鐵路撥款（Norton，2026-11-03）

巴士公司初期唔夠錢起地鐵，所以由政府注資，好似 1975 年政府注資地下鐵路公司咁：

- 立法會議案「地下鐵路撥款」（`metroRailwayFunding`，council-definitions.js）：要已成立運輸公司、人口 30,000。
  價錢係 $40,000 加 5 個月市庫收入；通過之後一定成功，市庫付嘅錢全數撥入運輸公司嘅**地鐵撥款**。
- 撥款同公司現金分開（`metro.grantBalance`），只可以用喺地鐵：起站、掘隧道、買列車會先用撥款，唔夠先用公司現金；
  巴士同渡輪用唔到。地鐵分頁顯示餘額，冇撥款時提示可以去立法會申請。
- 唔係一次過：冷卻 36 個月，每期新綫可以再申請。
- 議員：自由、旅遊支持；商界因為車站帶旺附近生意同物業而傾向支持；城市塞車（路面需要）係通過嘅關鍵。
  試玩：塞車城市大約九成五通過，唔塞車大約一半。
- 之後（第二期）：鐵路加物業，車站附近地價升值部分變成公司收入；銀行貸款暫時唔做。

## 7. 介面

- 運輸模式工具列加「地鐵站」工具；運輸視窗「路線」加「地鐵」分頁（巴士、渡輪之後）。
- 地鐵分頁：線表（名、顏色、站數、列車數、上月乘客同盈虧）、加站／刪站、買賣列車。
- 地圖：運輸模式入面，地鐵線用該線顏色畫虛線（表示喺地底），站畫圓點，列車畫細點。
- 「更多訊息」同財政表加地鐵一欄。
