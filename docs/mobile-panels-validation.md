## 已接駁範圍

| 入口 | 功能 |

`mobile-ui.js` 將原有視窗節點移入同一個手機面板，保留 ID、事件及原有解鎖／收費規則，唔複製模擬邏輯。關閉、返回、切換 profile 或轉城市時，以原位標記還原節點。返回堆疊保留上一頁捲動位置，圖表選項沿用原有狀態。交通公司未儲存文字有獨立草稿，避免被定時更新或語言切換清走。

直向使用全寬內容區及常駐底部導航；橫向使用右側面板，內容避開安全邊界並可捲動。桌面拖曳標題列、摺疊及縮放把手於手機面板隱藏，控制最少 44px 高。圖層地圖嘅手勢只控制該地圖。通知仍貼頂欄下方 4px，並置於手機面板之上，避免借貸或儲存回饋被遮住。

巴士選站只改編輯草稿：按「選擇站點」後暫時收起主面板，點站加入／移除，雙指縮放唔加站。「完成選站」返回同一編輯器；儲存路線仍經原有驗證。關閉路線視窗會取消該編輯器。新渡輪航線、地鐵／電車建造及延長等未支援手機草稿確認流程嘅按鈕暫停用；既有營運管理保留。
