## 透明邊界檢查

原圖 alpha > 0 範圍幾乎觸及畫布邊界，原因包括非常淡嘅殘留像素，唔係人物被裁切。當只量 alpha >= 16 範圍：

- 背面圖：`(79,193)–(1202,1012)`。
- 正面圖：`(35,127)–(1228,1138)`。
- 兩張畫布最外一圈都冇 alpha >= 16 像素。

主體 alpha 常見值係 252–253，接近不透明；少量邊緣有彩色／淡影殘留。製作接地 anchor 及裁切範圍時唔應直接用 alpha > 0 外框，否則會把殘留當成實際腳底。清理時應保留正常抗鋸齒及有意保留嘅接觸陰影，唔把所有半透明像素硬切掉。

## 等距與城市尺寸

視覺上接近由上方看嘅等距人物，身體垂直，較 UFO 仰頭群組適合望海加油。但圖中冇矩形地面或已知地面尺寸，所以未能嚴格驗證地面兩軸斜率係 ±0.5，亦唔應以任意人物連線當作地面軸。

接入仍須按每格 20 米校準：用個別成人頭頂至腳底（唔包含舉手）對照設計身高約 1.7 米，然後量腳底位置及群組佔地。唔沿用 UFO 群組 heightM 6，亦唔把整張圖嘅像素高度當成單一人物身高。兩張圖應分別量度，唔因畫布尺寸相同就假定縮放相同。

1254 唔係 2 嘅次方。完成清理、量度及必要校正後，透過既有素材流程輸出 1024 × 1024（或其他合適 2 次方長寬）及鏡像版本；維持人物長寬比例，唔拉扁身體來硬湊等距斜率。原圖須保留。
