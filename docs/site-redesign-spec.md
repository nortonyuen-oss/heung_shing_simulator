## 1. 現況問題（實測）

| 量度 | 電腦版 1440 闊 | 手機版 393 闊 |
|---|---|---|
| 首頁總高度 | 38,301px（約 43 個畫面） | 73,715px（約 87 個畫面） |
| 版本變更（93 個版本） | 19,287px | 50,699px |
| 截圖區（31 張連說明） | 13,372px | 15,571px |
| 硬件要求表 | 959px | 1,222px |
| 下載（5 張卡） | 745px | 1,844px |
| 頂部導航連結 | 14 條，再加 4 個語言 | 14 條 |
| 首頁文字量 | 約 30,800 字 | 同左 |

主要問題：
- **重點唔突出**：「即刻玩」同「下載」淹沒喺 14 條導航入面。首頁一半長度係版本紀錄，近三成係截圖。
- **兩段影片**（夜繽紛特輯、YouTube 預告片）連住排，各佔一個畫面。
- **版本說明愈寫愈長**：hero 嘅 versionDesc 每出一版就加一句（6.0.0…6.0.5…6.0.7）。
- **視覺唔一致**：深藍玻璃卡、金色按鈕、遊戲截圖混埋一齊，同遊戲兩套視覺都唔夾。
- **內部頁放咗喺公開資料夾**：`world-scale-*.html`（3.3MB 開發工具）同 `moderate.html`（版主工具）雖然冇放入導航，但都公開咗。
- **翻譯檔太大**：`docs/i18n.js` 有 600KB，每一頁都要成個載入。

## 2. 目標

1. **三秒睇得明**：首頁第一屏就交代清楚呢個係咩遊戲、點玩，即係「線上即玩」同「免費下載」，同埋最新版本有乜。
2. **短**：首頁電腦版唔多過 6 個畫面，手機版唔多過 12 個。其餘內容搬去獨立頁。
3. **一套美術語言**：見 §4，叫「香城 1999」。
   - 底子係《玩轉18區》嘅大航海時代風格：羊皮紙、酒紅、金邊、海圖。
   - 加港漫元素：粗墨線、大字標題、分格、對白泡、速度線、網點。
   - 套 90 年代 PC 遊戲官網嘅版面習慣：左邊導航欄、What's New 公告、大下載掣、訪客計數器、「最佳瀏覽解析度」襟章。
4. **用遊戲美術**：背景同插畫優先用遊戲入面嘅插圖，角色由遊戲人物擔任。唔另外買素材。
5. **功能唔減**：
   - 四種語言
   - 線上玩連結同下載連結（讀 `release-manifest.json`）
   - 遊玩次數同下載統計
   - 討論區、連儂牆、街坊福利會、宣傳2
   - 版權條款
   - Android 卡

## 4. 美術語言「香城 1999」

### 4.1 參考

- **大航海時代IV**（1999）：羊皮紙文件、酒紅金字標題牌、人物相框連名牌、航海圖、指南針。遊戲入面已經用緊同一套，即係《玩轉18區》對白框、市長登記、章節地圖。
- **港漫封面同內頁**（80–90 年代）：粗黑墨線、白字描黑邊加紅色投影嘅大標題、斜放分格、擬聲大字、集中線、網點陰影、對白泡。
- **90 年代 PC 遊戲官網**（光榮、大宇、Westwood 年代）：
  - 左邊導航用有立體斜邊嘅按鈕
  - 中間「What's New」新聞框
  - 大大個「Download」掣
  - 頁腳有「Best viewed in 1024×768」、訪客計數器
  - 閃動嘅「NEW!」貼紙

### 4.2 色票

| 名 | 色碼 | 用途 |
|---|---|---|
| 羊皮紙 | `#fcf5e1` → `#f2e4bf` | 內容框底色（漸變） |
| 深羊皮 | `#e6d3a3` | 次要底、表格間條 |
| 酒紅牌 | `#7a1f1f` → `#561313` | 標題牌、主要按鈕「線上即玩」 |
| 金邊 | `#c9a227` | 框邊、分隔線 |
| 牌金字 | `#f6d77a` | 酒紅牌上面嘅字 |
| 港漫墨 | `#14100c` | 墨線、粗框、大字描邊；網站深底色係 `#1d140d` 嘅木啡 |
| 港漫紅 | `#d7261e` | 大字投影、NEW! 貼紙、擬聲字。只做點綴，唔用嚟做大面積底色 |
| 遊戲深綠 | `#123f38` / `#1a6f5a` | 左邊導航按鈕、「即玩」綠標，同遊戲主題呼應 |
| 海圖水 | `#527a96` | 只用喺地圖入面嘅海，屬功能色 |

遊戲入面嘅規矩照用：**唔用藍色做框或者按鈕**。

### 4.3 字體

| 層級 | 字體 | 樣式 |
|---|---|---|
| 港漫大字（Logo、段落大標） | Noto Serif TC 900 | 白字、3px 墨描邊、右下紅色投影，再加一層墨投影 |
| 標題 | Noto Serif TC 900 | 酒紅色；放喺標題牌上就用牌金字 |
| 正文 | Noto Sans TC 400/700，16px，行距 1.7 | 墨色 |
| 英文小標、章節號 | Cinzel 700，字距 3–4px | 啡金色，例如「CHAPTER XII」 |
| 數字計數器 | Courier New 粗體 | 黑底綠字，扮 LED |

- 日文：用 Noto Serif JP 或 Noto Sans JP，規則同上。
- 英文：大字用 Cinzel，正文用系統 sans-serif。
- 全部係真文字，唔整做圖片，方便翻譯、搜尋同無障礙。
- Logo 第一階段用 CSS 大字；之後可以請 ChatGPT 出一張港漫題字 Logo 圖，Logo 係唯一例外，可以用圖片。

### 4.4 元件

| 元件 | 樣式 | 用喺邊 |
|---|---|---|
| 羊皮紙框 | 同遊戲對白框一樣：3px 金邊、外圈 5px 酒紅、再一圈金、內有一條細金線 | 所有內容區塊 |
| 標題牌 | 酒紅漸變、2px 金邊、牌金字、字距 3px | 每段標題、頁面標題 |
| 人物相框 | 羊皮紙襯底、金邊、酒紅外圈、紫紅名牌（同遊戲市長卡、關於頁一樣） | 角色介紹、作者、福利會 |
| 港漫分格 | 4px 墨框、輕微斜放（±0.6–1°）、格與格之間留羊皮紙縫、左下角放羊皮紙字牌 | 遊戲特色、畫廊精選 |
| 對白泡 | 白底、3px 墨框、橢圓、三角尾巴、5px 墨投影 | 網站導賞員講嘢、角色金句 |
| 擬聲大字 | 黃字、墨描邊、斜 8°（例如「轟！」「叮叮！」） | 每格最多一個，點綴用 |
| 集中線、網點 | CSS 重複錐形漸變、圓點網點 | 頭版背景、CTA 區 |
| 90s 立體按鈕 | 上左光邊、下右暗邊 | 左邊導航（深綠；所在頁用酒紅）、下載掣 |
| 主要按鈕 | 「線上即玩」：酒紅金字、立體邊；「免費下載」：金色墨字、立體邊 | 頂欄、頭版、下載區 |
| NEW! 貼紙 | 港漫紅底白字、墨邊，一秒一閃，可以關 | 最新密令第一條 |
| 計數器 | 黑底綠字逐格數字 | 線上遊玩人次、下載次數 |
| 襟章 | 88×31 小襟章：「Best viewed 1024×768」「香城市政規劃局 Presents」「Made in Heung Shing」 | 頁腳彩蛋 |
| 航海圖 | 地圖加少少復古色、金框、指南針、章節圓點 | 玩轉18區 |

### 4.6 動態

- 標題牌入場：蓋印咁「啪」一聲落位，0.25 秒。
- 港漫分格：滑鼠移過時放大 2%，斜度歸零。
- 集中線：慢慢轉。
- NEW! 會閃。
- 系統設定減少動態（`prefers-reduced-motion`）時，以上全部停晒。
- 唔用視差捲動同自動播放影片。

## 8. 技術

- **部署唔變**：仍然係靜態 GitHub Pages，由 `scripts/build-official-site.js` 複製 `docs/`。
- **樣式**：新增 `docs/site-1999.css`，色票同元件用 CSS 變數定義；舊 `styles.css` 喺改版完成後刪走。

- **翻譯**：
  - 拆 `i18n.js`：首頁字串、攻略、社區、版本紀錄各自一個檔，每頁只載自己用嘅。

- **要保留嘅邏輯**：
