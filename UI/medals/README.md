# 洋紫荊勳章原創圖案

五瓣琺瑯洋紫荊、花瓣內五角星、金屬雕邊、月桂葉及紫色綬帶。銅／銀／金以金屬材質區分；黑紫荊用深紫琺瑯，紀念章用淡紫色，大紫荊加放射章框。未解鎖的隱藏勳章使用中性問號圖案。

向量原始碼：`medal-art.js`。遊戲使用內嵌 SVG，免額外網路請求，並為每個漸層產生獨立 ID。此目錄是方便獨立使用的匯出檔；以下指令可重新產生：

```sh
node scripts/generate-medal-art.js
```

面板與圖案預覽、互動／手機檢查：

```sh
node scripts/smoke-medal-cabinet.js
```

預覽輸出至 `.data/medal-cabinet/`。等級依現有勳章定義，沒有額外更改授勳條件。
