# 手機版 Phase B 原型驗證（2026-11-11）

分支：`feature/mobile-ui`；版本保持 `5.5.1`，未發布。沿用已凍結 B0 設計稿；自動切換仍然關閉。

## 開啟方式

主選單「介面」揀「觸控（Beta）」；遊戲內亦可於桌面「設定」或觸控「更多」切換。選擇存在介面偏好，不進入城市存檔。網址 `?ui=touch` 只覆蓋今次載入。

同一 Wi-Fi 真機預覽：`STATIC_HOST=<Mac 的 Wi-Fi IP> PORT=4186 node scripts/static-web-server.js`，手機開 `http://<該 IP>:4186/?ui=touch`。預設仍只監聽 localhost。普通 HTTP 預覽不使用離線 service worker；即使瀏覽器未提供 `crypto.randomUUID`，亦會繼續啟動儲存及自動存檔。

直向及橫向建造：選工具 → 點位置（道路／分區／框選拆除要點 A、B）→ 睇成本及有效格／影響摘要 → 微調 → 確認。單指拖動平移，雙指縮放；手指放開不提交。直向建造時保留底部五個入口，取消／確認排第二行，狀態摘要有足夠高度顯示。
