坐姿人物與枱凳分層。人物手上保留碗、匙、竹籤及食物。每個檔案只包含一人；以 `sp_` 為檔名前綴。這批是靜態姿勢，路人採跨步姿勢。

投影以現有 1:2 等角街檔作視覺參考；人物沒有可直接量度的兩組硬直角邊，沒有套用車身仿射拉伸。`heightM` 是建議遊戲身高，尚未作場景內米制校位。腳點與坐姿座點是配置初值；座點人工估計誤差約 15–25 原圖像素，正式擺上摺凳時仍需檢查重疊及遮擋。尚未登記至遊戲 runtime。
