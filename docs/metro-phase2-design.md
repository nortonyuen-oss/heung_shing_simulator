# 地鐵 — 第二期設計 v0.1（鐵路加物業、轉車站）

日期：2026-11-04。狀態：Norton 已決定（§5），開始做。第一期：`metro-design.md`。

第二期做兩樣差唔多唔使新美術嘅嘢：

1. **鐵路加物業**：每個站每月按附近地價升幅收物業收入。地鐵公司唔使永遠靠撥款，好似港鐵咁靠物業養鐵路。
2. **轉車站**：一個站可以有幾條綫經過，乘客可以轉綫，地鐵先至成為網絡。

唔做（留第三期）：高架同地面路段、路軌同列車美術（Norton 已有基本素材）、輕鐵、電車、銀行貸款。

## 1. 現況（第一期）

- 一個站只可以屬於一條綫（`getMetroStationLine`），畫綫時撳到其他綫嘅站會話「轉車站第二期先有」。
- 每個站有一條隊（`station.waiting`），按巴士站上班曲線逐個鐘加人；列車到站時，隊入面向住列車方向嗰部分上車。
- 車費：上車 $0.05，每格 $0.002（公司元）。三個站嘅過海綫大約一年回本，即係每個站每月賺大約 $1,500–2,000。
- 城市效果：站 10 格內商業地價最多 +15%，住宅快樂度、工業需求加成，路面車流最多減 40%。
- **市庫收入唔係按地價計**（`computeBudgetSnapshot`：按人口同商住工建築數目），所以「地價升咗」本身唔會變錢，
  要另外計一筆物業收入。

## 2. 鐵路加物業（Norton 揀：每月分地價升值）

港鐵嘅做法係鐵路令站附近地價升，港鐵分升值嗰部分。遊戲用最簡單嘅版本：唔使申請、唔使等興建，
每個站每月自動收**物業收入**。

- **邊啲建築計**：有列車行走嘅綫上每個站，10 格內嘅住宅同商業建築。
- **升幅**：同第一期地價效果一樣：服務質素（0–1）× 15% ×（1 − 距離 ÷ 11）。一座建築喺幾個站範圍內，
  只計升幅最大嗰個站，唔會重複收。
- **慢慢升**：新站嘅升幅由 0 開始，通車 12 個月先升到足（`station.servedMonths`），好似真實樓價追落成。
- **每月收入** = 升幅 × 建築等級（1–3）× 佔地格數 × 每格租值（`METRO.propertyRatePerTile`，按試玩城市校準：
  舊區大站足額大約每月 $800–1,000，即係大約車費嘅一半）。每個站上限每月 $2,000。
- 收入入公司現金，月結多一欄「物業收入」（同車費分開，方便睇鐵路本身賺唔賺）。
- **地圖**：運輸模式入面，有物業收入嘅站喺圓點旁邊加細屋仔標記；綫卡車站列表顯示每個站上月物業收入。
- 地鐵分頁顯示全公司上月物業收入。

## 3. 轉車站

### 3.1 畫綫

- 畫綫時可以撳其他綫嘅站：該站變成**轉車站**，只付隧道錢，唔使再起站。
- 冇喺畫綫時：
  - 撳一條綫嘅**尾站**：延長該綫（同第一期一樣）。
  - 撳一條綫嘅**中間站**：由呢個站開新綫（第一期會拒絕）。
- 「新增地鐵綫」掣：之後第一下一定開新綫，就算撳尾站都係，方便由轉車站開出。
- 一條綫唔可以經過同一個站兩次。拆綫時，轉車站留畀其他綫用。

### 3.2 乘客

- 每個站每條綫各有一條隊（`station.waitingByLine`）。新乘客按每條綫由呢個站去到嘅站數分配。
- 喺轉車站落車嘅人，有一部分轉去其他綫：比例 = 其他綫去到嘅站數 ÷（其他綫 + 本綫去到嘅站數）。
  佢哋排入其他綫嘅隊，**轉綫唔再收上車嘅基本車費**，只收每格車費（同港鐵一樣按全程計）。
- **網絡效應**：一個站嘅乘客數按全網去到幾多個站而增加：

  乘數 = 1 + 0.5 × min(1, 轉綫先去到嘅站數 ÷ 本綫站數)

  即係全網去到嘅站數係本綫兩倍或以上時，最多多 50% 人搭。
- 舊存檔：`station.waiting` 撥入佢唯一嗰條綫嘅隊。

### 3.3 地圖同介面

- 運輸模式：轉車站畫白色圓點加黑邊，好似港鐵路綫圖。
- 綫卡車站列表：轉車站旁邊顯示其他綫嘅顏色點。
- 車站可以改名（第一期得綫可以改名），轉車站要有個好名。

## 4. 存檔同測試

- 存檔：`station.waitingByLine`、`station.transferByLine`、`station.servedMonths`、`station.lastPropertyIncome`，
  全部喺 `normalizeMetroState` 補預設值；公司月結加 `metroProperty`；運輸 schema 唔使升級。
- 測試（test/metro.test.js）：物業收入公式（升幅、慢慢升、唔重複收、上限）；轉車站畫綫規則；轉綫唔收基本車費；
  網絡效應乘數；舊存檔隊伍轉換；拆綫保留轉車站。
- 試玩：太子／旺角兩條綫交匯，睇轉綫人數同物業收入合唔合理。

## 4.1 試玩（2026-11-04，太子示範城市，34.8 萬人）

- 物業收入（每格 $40，足額）：太子任何一點起站，中位數每月 $484，九成以下 $951，最高 $1,160，冇站撞到 $2,000 上限。
- 兩條綫（荃灣綫三個站、港島綫兩個站過海），喺第二個站交匯，每條綫 4 列車：
  - 每月乘客 97 萬同 63 萬；轉綫乘客 28 萬（港島綫轉荃灣綫）同 7 萬。
  - 物業收入由第一個月 $168 升到第十二個月 $2,021，之後不變。
  - **車費每月 $93,000 同 $65,000，物業收入只係車費嘅大約 1%**：大城市車費好高，一條綫一個月就回本，
    呢個係第一期車費喺大城市嘅平衡問題，待 Norton 決定。

## 5. 已決定（Norton，2026-11-04）

1. 物業模式：每月分站附近地價升值（唔使申請同興建）。
2. 地圖：唔起真樓，運輸模式有物業收入嘅站加標記。
3. 轉綫唔再收基本車費，只收每格車費。
4. 網絡效應：要，全網去到嘅站越多，站嘅乘客最多多 50%。
