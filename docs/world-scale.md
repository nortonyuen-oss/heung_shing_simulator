# 世界比例規範（草案）

日期：2026-10-17。目的：所有素材（建築、車輛、人物、道具、路面）跟同一套「每米幾多 px」，由測試守住。本文件分階段完成；現時只有第一階段（量度）。

## 現況與發現

- 玩法單位：一格 = 20m（`TILE_WIDTH` 100px、`TILE_HEIGHT` 50px），即沿地圖軸每米水平 2.5px。
- 人物、路邊設施、節慶道具、避風塘、UFO、搶包山：高度每米 5px（zoom 1），在 6 個 module 各自定義（`STREET_FURNITURE_PX_PER_METRE`、`FESTIVAL_PX_PER_METRE_UP`、`TYPHOON_SHELTER_PX_PER_M_HEIGHT`、`BUN_HILL_UP_PX`、`UFO_PX_PER_METRE`、`FESTIVAL_STALL_GEOMETRY_PX_PER_METRE_UP`）。
- 真實 2:1 投影（鏡頭俯角 30°）中，直立 1m 的畫面高度 = 沿軸 1m 的水平寬度 × cos30/cos45 ≈ 1.22。以一格 20m 計應為每米高 3.06px；5px/m 相當於一格約 12m 的真實比例。
- 路面與車輛：雙線行車路路邊石之間約 9.3m（以 20m 一格量），真實約 7m；私家車、巴士以一格 15m 計約為真實 0.85–0.9 倍。即路面及車輛的畫面比例約為一格 15m。
- 建築：按地盤闊度貼合（`applyBuildingGroundFit`），高度跟原圖，比例未知；Norton 估計大部分約一格 20m，部分更細，屋苑式可達一格 40m。
- 街燈、巴士站、樹、車輛用人手 scale 常數，沒有米制依據。

結論：畫面上同時存在約 12m（人物）、15m（路面車輛）、20m 至 40m（建築）幾套比例。

## 階段

1. **量度（已完成工具）**：測試模式「校正工具 → 建築 → 建築比例量度」。點選建築，在立面由下向上拖一段已知高度（層數 × 每層高度，預設 3m），工具計出該模型每米高度、相對人物倍數及推算一格米數，並在旁畫出 1.7m 人物及一層樓（均按 5px/m）作目視比對。只作記錄，不改畫面。「複製 JSON」存為 `data/building-scale-survey.json`，`node scripts/building-scale-report.js` 輸出排序表、分佈及未量度模型清單（現有 167 個建築模型）。
2. **定標準（已決定）**：一格 20m，見下文。
3. **常數與守衛**：建立 `world-scale.js` 單一來源，取代各 module 的 px/m 及每格米數；加測試：素材須登記真實尺寸及類別，渲染尺寸偏離標準超過容差即失敗；禁止在 `world-scale.js` 以外硬寫 px/m。
4. **逐批修正**：由偏離最大的模型開始，每批一個 commit（參考維園六模組的做法）。

Norton 決定：#1 residential4-01-M-MD → 3×3（另剪走地面巴士站車位及劃線）、#2 residential2-05-L-MD 縮圖補地台（待做，加路邊小物）、#3 residential3-08-M-MD → 4×4、#4 residential2-02-M-HD → 3×3、#5 小學 → 3×3、#6 residential2-10-H-MD → 3×3、#7 醫院 → 5×5、#8 residential3-07-M-MD → 4×4、#9 中學（兩款設計）→ 4×4、#10 不改（覆量後一格 18.2m）。

舊存檔已建的同款建築保留舊佔地：住宅模型由新佔地的組別「借用」（`borrowedFiles`），舊組別保留為 legacy（`legacyFiles`，只供存檔解析、不再生成）；學校及醫院用新 sprite key，舊 key 留作 `LEGACY_SERVICE_BUILDING_MODELS`（共用貼圖及燈光）。

大型屋苑：residential5-01/5-02-H-MD（YOHO，一格約 41m）改 10×10、residential5-03-L-HD（約 32m）改 8×8；新增借用式 `house8x8`／`house10x10` 組別，5×5 三款轉 legacy。高密度住宅地的大地塊掃描按 10×10 → 8×8 → 5×5 嘗試。起樓道路距離由 3 格放寬至 5 格（100m，`ZONE_ROAD_ACCESS_TILES`），大地塊任何一格近路即可，為日後公共屋邨鋪路。YOHO 圖中的巴士、巴士站及路口劃線自動修補效果不佳（行人路物件太密），暫未改圖。

量度用存檔「樓宇模型目錄」：平坦地圖上按類別及佔地沿路排列全部 155 個現行模型（住宅 37、商業 26、工業 17、政府 23、特殊 37、公園 15），載入後先暫停再量度。



- **改佔地**：遊戲按地盤貼合縮放，改 N×N → n×n 即按 n/N 放大／縮細，毋須改圖。影響玩法（區劃地塊大小）及舊存檔中已建的同款建築；可沿用 `airport_6x6_legacy` 的做法，舊存檔保留舊佔地的 legacy 版本。
- **放大裁切**：建築居中、外圍是花園空地的圖（如 #3、#8），放大後沿新地盤裁走外圍，佔地不變。
- **縮細補地台**：畫得太大又不能再縮佔地（#2、1×1 建築），建築縮細放回原地盤，四周補地台或花園（參考遊艇會的淡地盤底）。
- **重畫**：以上均不合適時（#1 想保留 4×4 屋苑、#7 想保留 4×4 醫院）。

## 量度注意

- 一格米數假設原圖接近真實投影（AI 生成圖經 `correct.py` 校正後大致成立）；量度記錄當時的 sprite scale，模型地盤角或佔地改變後須重量。
- 樓層高度：住宅約 2.8–3.0m，商業／政府約 3.5–4m，地舖可較高；跨多層量度可減少誤差。
