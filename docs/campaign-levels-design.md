## 1. 結論

- **地圖唔使等全境 chunk。** 遊戲已經有 23 張香港地區實景地圖（`hk-district-maps.js`，地政總署 5 米地形，每張 256×256 格＝5.12 公里），18 章入面 17 章有對應地圖。黃大仙可以暫用九龍城圖北邊，或者用 `scripts/build-hk-district-maps.py` 加一張。
- **開局唔使寫程式擺嘢。** 遊戲已經識載入「打包存檔」（showcase 城市就係咁：`UI/attract-city.json`）。每章開局由你喺遊戲入面砌好，用工具匯出做 `UI/campaign/chNN.json`。
- **6 章一星而家已經可以玩**（01、02、03、04、07、12），全部條件都係現有系統；7 章要補細嘢；5 章要新系統。
- **你有幾個存檔啱啱好做到開局**：香港仔（37,428 人，香港仔實景圖）→ 第 04 章；堅尼地城（156,007 人，維港實景圖，屬中西區）→ 第 18 章底；太子／旺角（三十幾萬人，屬油尖旺，但係舊圖）→ 第 17 章參考。
- **建議實作次序**：先做共用框架＋第 01 章，玩通一次再複製去其餘章節。

## 2. 共用關卡框架

### 2.1 開局

| 方式 | 用法 | 機制 |
|---|---|---|
| 預砌開局（建議全部章節都用） | 你喺遊戲用對應地區地圖砌好開局城市，撳「匯出為章節開局」 | 同 `exportAttractCity()` 一樣寫 `UI/campaign/chNN.json`；開章時用 `decodeSaveDataForLoad`＋`applySaveData` 載入，唔佔存檔位，即係 attract mode 嗰條路 |
| 全新開局（後備） | 冇預砌檔就用地區地圖開新城 | `startNewGame(名, { terrain, districtProfileId })` |

預砌開局可以完全控制起步資金、村屋、道路、問題（例如第 07 章塞車、第 15 章治安差），唔使逐樣寫腳本。

### 2.2 章節狀態（跟城市存檔）

開章時喺城市寫入 `city.campaign`：

```
{ chapterId: 'ch01', startMonthIndex, deadlineMonthIndex: start + 12,
  starsEarned: [], firstStarMonthIndex: -1, failed: false,
  baseline: { commercialTax, industrialTax, ... },   // 第 13 章「稅收增長 20%」等要對比開局
  events: { midEventShown: false, ... } }
```

存檔用 `Object.assign` 還原（同 `city.medalLog` 一樣），所以玩到一半可以照常儲存、載入。

### 2.3 計時同星級

- 每月 `gameclock:month` 判定（勳章用緊同一個時機）。
- **一星**：12 個遊戲月內所有條件同時成立即時通關；解鎖下一章；播通關對白同討論區帖。
- **二星、三星**：同一個存檔繼續玩，不限時；每月判定。
- **失敗**：到期未有一星 → 畫面畀兩個選擇：「重新開始本章」或者「繼續自由建設（本章唔再計星）」。
- 條件判定沿用勳章嘅城市快照（`collectMedalSnapshot`），加章節要嘅欄位。

### 2.4 進度（跟玩家，跨存檔）

同勳章一樣存喺 `player_profile`（key `campaign`）：每章最高星數、首次一星日期、用咗幾多個月。改 `server.js` 條路由做 `/api/player-profile/:key`（白名單 `medals`、`campaign`）。18／18 一星 → E01 九龍皇帝勳章由「即將推出」變做判定緊。

## 4. 第 01 章 北區《新任市長上場》詳細設計

### 4.1 開局

- 地圖：`sheung-shui`，地區特色 `sheung-shui`。
- 預砌：幾條簡單道路、一個小巴站、幾間村屋、一兩間工場、一座政府辦公室；**冇電廠**；資金充足但唔多〔暫定 $20,000〕。
- 開場對白（劇本 PROLOGUE 到埗＋開場劇情），然後系統字卡「任務開始」。

### 4.1a 教學（Norton 2026-11-17：記得第一關有教學）

放喺目標面板最上面，一步一步做；每步左邊「建設指引」對應嘅掣會閃黃框；做完自動跳下一步（彈「✓ 完成」），可以「跳過教學」。「起路」「拉電線」以開章時嘅數量計，原本已有嘅唔算。

| 步 | 講者 | 內容 | 完成 |
|---|---|---|---|
| 1 | 金毛玲 | 路政署 → 道路，將村屋同外面駁通 | 新增道路 ≥ 5 格 |
| 2 | 金毛玲 | 電力水務 → 起發電廠（燃煤 vs 太陽能） | 有發電廠 |
| 3 | 金毛玲 | 拉電線去準備發展嘅地方 | 新增電線 |
| 4 | 金毛玲 | 城規會 → 住宅區（R） | 有住宅分區 |
| 5 | 財政官 | 商業區（C）同工業區（I），工業放遠啲 | 商業同工業分區都有 |
| 6 | 街坊 | 公共設施 → 消防局 | 有消防局 |
| 7 | 財政官 | 睇住每月收入同支出，稅唔好加太多 | 撳「明白」 |

### 4.2 一星《城市正式開張》（12 個月）

| # | 條件 | 判定（快照欄位） |
|---|---|---|
| 1 | 有電 | 有發電廠，且 `powerRatio` ≥ 1（供電足夠） |
| 2 | 住、商、工都有實際建築同就業 | 住宅、商業、工業建築各 ≥ 1，失業率 < 15%〔暫定〕 |
| 3 | 常住人口達 3,000 | `population` ≥ 3,000 |
| 4 | 每月經常性收支正數 | 每月收入 > 支出，且冇未還貸款〔暫定，「避免無上限借貸造假盈餘」〕 |
| 5 | 基本滿意度同服務 | 滿意度 ≥ 50%〔暫定〕；有消防局（冇垃圾系統，用消防代） |

### 4.3 二星《小鎮有小鎮嘅幸福》（不限時）

人口 ≥ 10,000〔暫定〕、失業率 < 8%、至少一條有乘客嘅巴士線（交通公司 3,000 人解鎖）、警署＋消防局＋醫院＋公園各 ≥ 1。

### 4.4 三星《北區新市鎮》（不限時）

人口 ≥ 30,000〔暫定〕、連續 12 個月盈餘（沿用 A19 嘅計數）、滿意度 ≥ 75%、交通指數 ≤ 0.4〔暫定〕。

### 4.5 中段事件《有地就起？》

- 觸發：人口首次過 1,500 且住宅需求高（遊戲冇賣地收益，用呢個代）。
- 對白：金毛玲建議全部改劃住宅；財政官提醒職住失衡。唔加機制分支，玩家照常自己規劃。
- 討論區帖：「市長上任三個月已起咗兩條路！」「笑死，之前嗰兩條仲未駁埋。」

### 4.6 通關

金毛玲、署長對白；女皇冇短訊（第 03 章後先有）；解鎖第 02 章。

## 4.7 開局檔（你要做）

而家冇 `UI/campaign/ch01.json`，第 01 章用上水地圖開新城（$20,000）。你想要劇本講嘅「幾條道路、小巴站、村屋、零星工場」：喺 Electron 開發版用上水地圖砌好（唔好起電廠），喺 DevTools console 打 `exportCampaignStart('ch01')`，就會寫 `UI/campaign/ch01.json`（只限開發版；匯出時會清走章節狀態）。
