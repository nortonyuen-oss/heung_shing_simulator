# 地鐵 — 第三期設計 v0.1（地面同高架）

日期：2026-11-05。狀態：Norton 已決定（§8），開始做。第一期：`metro-design.md`；第二期：`metro-phase2-design.md`；
路軌格：`railway-track-system.md`。

## 1. 目標

第一、二期嘅地鐵全部喺地底，地圖上只見到出入口。第三期令列車喺地圖上行：玩家起路軌，列車喺上面跑，
好似示範環（2026-11-04）咁。

已經有（已 commit）：
- 雙軌路軌格（一格一條綫，兩條路軌相距 4 米），直路、細彎、分岔、交叉；`railway-track.js`。
- 大彎：2 × 2 格，半徑 30 米（`RAILWAY_TRACK_LARGE_CURVES`）。
- 列車示範：Norton 嘅 `MTrains` 車頭卡（每幅一頭車頭、一頭接駁位），中間卡由兩幅拼出；斜升方向用斜落翻轉；
  按紅色腰綫拉正到 0.5（`scripts/metro-train-demo/`，未入遊戲）。

## 2. 起路軌

- 新工具「地面路軌」（運輸模式 → 地鐵）：好似起路咁拖。好似 OpenTTD，每格記 TrackBits（`railway-track.js`）：
  - 直拖：直路（X 或者 Y）。
  - 拖 L 形：轉角嗰格係一段斜綫，即係兩次 45° 轉彎（Norton，2026-11-05：TTD 嘅 45° 轉彎好睇好多，
    取代咗之前試嘅弧形同 2 × 2 大彎）。
  - 斜住拖（橫同直差唔多一樣遠）：一條斜向路軌，由斜塊一級一級砌成，喺畫面上係橫綫或者直綫。
  - 跨過另一條直路：自動變十字交叉。分叉（道岔）第三期未有，會拒絕。
- 只可以起喺平地、空地（冇建築、冇路）。斜坡、水面同過馬路見 §4。
- 費用：每格 $500（地底隧道每格 $300，但地面要買地、起路基），每月每格保養 $2。
- 推土機拆一格路軌（有地面綫用緊嘅格之後唔准拆，第三步做）。
- 存檔：`metro.tracks`，每格嘅 TrackBits；地圖轉嘅時候每個 bit 嘅兩邊跟住轉，再揀返對應嘅圖。

## 3. 地面站（已做，2026-11-05）

- 工具「地面站」（$8,000）：撳五格直路軌中間嗰格；四卡車大約 90 米，月台 **5 格**。月台兩邊各一
  （離綫中心 4–9 米，高 1.1 米，灰色地磚、黃色警示綫），上面有玻璃上蓋同鋼柱（8 米高，喺車頂之上；
  遊戲嘅列車高過真實）。唔使貼馬路（Norton）。
- 每格三幅圖（`scripts/prepare-metro-platform-assets.py` → `Models/metroPlatform/`）：月台（喺地面，
  列車下面）、後面上蓋（列車前畫）、前面上蓋（列車後畫），所以列車喺兩個上蓋之間。
- 站嘅乘客、車費、覆蓋範圍、物業收入同第一、二期地底站一樣（同一個 `stations` 表，`surface: true`）。

## 4. 過馬路同地形

- 港鐵冇平交道。兩個做法：
  - **高架**：路軌行喺橋墩上面，跨過馬路同建築。高架格 = 路軌格 + 混凝土橋面 + 橋墩，同樣用程式畫。
    上落高架要斜坡（大約 3 格）。
  - **平交道**：路軌直接過馬路，好似輕鐵。簡單，但唔似港鐵。
- 水面：第一期嘅地底隧道已經可以過海，地面路軌唔過水。

## 5. 地面綫同列車（已做，2026-11-05）

- 「地鐵綫」工具一個地面站接一個撳：沿路軌搵路（`findSurfacePath`，逐格跟 TrackBits），唔使隧道錢；
  冇路軌連住或者地面站同地底站混合都會拒絕。
- 列車由時鐘計位置（同地底一樣），速度每分鐘 1.4 格（Norton：比 2 格慢 30%），停站 2 分鐘。
- 每列四卡（頭卡、兩卡中間、尾卡），按方向揀 `Models/metroTrain/` 嘅圖，靠左行（港鐵）。
  每卡按自己喺綫上嘅位置揀路軌，所以轉彎同過渡綫都係一卡跟一卡。
- **總站掉頭**（Norton，參考港鐵）：總站月台外兩格有剪式渡綫（`metro_track_crossover_*`）。列車入站時
  經渡綫揀一邊月台（每列車輪流），停站之後離站時經同一組渡綫返去靠左嘅路軌。
- 有地面站或者有地面綫行緊嘅路軌唔准拆。

## 6. 同第一期地底綫點樣夾埋

- **做法 A：一條綫可以一段地底、一段地面。** 兩個站之間，如果有路軌連住就行地面，冇就掘直綫隧道。
  地底同地面之間要隧道口（斜坡落地底，要一款新圖）。最似真港鐵（觀塘綫、荃灣綫都係咁）。
- **做法 B：第三期先做獨立地面綫。** 一條綫全部地底或者全部地面，唔混合。簡單好多，隧道口留第四期。

## 7. 存檔同測試

- 存檔：`metro.tracks`（每格嘅 TrackBits）、`metro.surfaceStations`；運輸 schema 唔使升級。
- 測試：拖路軌揀格（直路、L 形 45° 轉角、斜綫、交叉、拒絕道岔）、月台長度、列車沿路軌嘅位置同方向、拆路軌限制。

## 8. 已決定（Norton，2026-11-05）

1. 第三期做獨立地面綫：一條綫全部地底或者全部地面，唔混合；隧道口留第四期。
2. 過馬路用高架（港鐵冇平交道）。
3. 月台同高架用程式畫，同路軌風格一致。
