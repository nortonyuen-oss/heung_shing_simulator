# 路邊設施（垃圾桶／電箱／郵筒／咪錶）擺放設計

## 2. 擺放位置（slot）

一格直路（`road_straight_v/h`，包括雙線 band 格）每條有行人路嘅路邊（對面唔係馬路）分兩半格，每半格叫一個 slot，最多放一件嘢。已經有欄杆、路燈嘅 slot，同埋有巴士站嘅格，都唔放。

每件嘢面向鏡頭（兩個 view：`sw` 用喺畫面 NW–SE 走向嘅路，`se` 用喺 SW–NE 走向嘅路），所以唔使背面圖。

## 3. 規則（按優先次序爭 slot）

1. **交通燈控制箱**：每個有燈號嘅路口（成舊雙線路口都當一個）一個，放喺第一支燈柱嗰邊路邊、遠離路口嗰半格。
2. **郵筒**：一條「街」＝同一方向連續直路（到路口／彎／盡頭為止）。如果兩邊有樓嘅格佔 ≥1/3，而有樓嘅入面住宅佔 ≥50%，就係住宅街。機率 = 0.4 ×（0.5 + 密度），限 10%–60%；密度 0.5 時就係用戶指定嘅約 40%。擺喺街中間附近、住宅嗰邊。
3. **巴士站垃圾桶**：70% 巴士站喺隔籬格有一個（食環署：巴士站係主要放置點）。
4. **咪錶**：只放雙線（band）格、行人路嗰邊，交通量低先有：負荷 ≤0.15 → 85%，0.15–0.35 線性減，≥0.35 → 冇。路口前一格／斑馬線（有欄杆嘅格）、巴士站同隔籬都唔放（香港唔可以喺路口同巴士站泊車）。每格最多一個（每錶約 1.8 個位 ≈ 一格路邊）。
5. **垃圾桶（密度）**：3% + 20% × 密度²；路口前一格 ×1.5（食環署：主要路口）。滿樓街每格約 23%，空地約 3%。
6. **電箱（中電／電訊）**：1% + 5% × 密度。

**密度**：呢格同前後各一格，兩邊對面嗰格有冇樓：有樓計 0.7／0.85／1.0（樓高 level 1／2／3），冇樓 0，六格平均。兩邊都起滿先接近 1。

所有機率用格座標嘅固定 hash 抽，所以同一條街每次重建結果一樣，除非周圍變咗。

## 4. 重建時機

- 起路／拆路／巴士站：下一個 tick 重建，同時重新讀交通量。
- 樓宇落成／清拆：等 5 秒一齊重建（`STREET_FURNITURE_GROWTH_REFRESH_MS`），而且沿用上次讀到嘅交通量，免得咪錶因為交通量跳嚟跳去而閃。
- 一次重建大城（太子）約 25–40 ms。
