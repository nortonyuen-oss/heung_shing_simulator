# 全境定位與載入效能修正

日期：2026-11-15。延續共用原遊戲場景的全境模式，保留原地形、建設資料與存檔格式。

## 地標與小地圖

上一輪只比對地形資料／底圖，漏驗原遊戲小地圖的實際點擊。512×256 Canvas 的全境繪圖與點擊逆轉換，分別用了 Canvas 高度及長方形地圖的 gridHeight，造成約 12 km 誤跳。鴨脷洲及啟德跑道仍在原資料，但按地圖會去另一地區。

原小地圖現接到 WorldGameMinimap，底圖、道路／建築、地鐵線、點擊及鏡頭框共用 WorldMinimapTransform。全境模式新增「全境／區域」兩個按鈕，區域顯示附近 256×256 格（5.12 km），附目前地區提示；拖動期間固定地圖範圍，放手後才跟隨鏡頭。普通 256×256 城市保持原變換及介面。

手機原介面會隱藏桌面小地圖，現只在全境遊戲期間顯示同一個面板，加大切換按鈕；離開全境時隱藏，導航亦會取消未確認的建設草稿。偏好獨立保存，不更改城市座標。

`npm run smoke:world:geography` 從真實畫面上的小地圖座標點擊，驗證鴨脷洲、啟德跑道、主畫面／區域圖的陸地與兩旁水道，四個旋轉方向、手機觸控、儲存重載及零建設副作用。原生 Safari 亦以 WebDriver pointer actions 驗證兩個地標及兩個範圍。

## 減少讀取與重複工作

- 「開新城市」先列出普通地圖，全境放最後，普通地圖為預設。
- 原 670,178 bytes（未壓縮）的 hk-terrain-tiles.js 不再是 HTML 或 Service Worker shell 的啟動依賴。只有明確使用舊「隨機香港實景」取樣器才載入，並發讀取共用 Promise，失敗可重試；全境開城／續玩只用原 packs 與小型 metadata。
- 遲到的預覽即使在進入全境後才完成下載，也只生成自己的 256×256 地圖；同步計算結束或失敗時立即還原原尺寸，避免意外生成 765 萬格。並發預覽共用結果，不重複生成。
- 稀疏 grid 在實際寫入時建立 Render Chunk 索引及類型計數；讀取未開發地區不建立索引。道路／分區顯示只查所需 Chunk，摘要中的道路開支使用計數，避免重掃所有已建道路。這些索引不寫進存檔，摘要表仍是原先要求的基本欄位。
- 空白地形的 viewport 候選可直接由稀疏道路索引排除，不需要反覆取樣、解碼或配置地形列。道路／分區圖片按視野建立，資料繼續保存。
- 鏡頭、Chunk 與建築未變時，跳過地形裁切、區域底圖候選、建築掛載整理及小地圖框的重複更新。城市小地圖圖層亦按資料版本／範圍快取，以一次 ImageData 寫入取代數萬次 fillRect；區域模式只查當區索引。

## 密集道路的 GPU 瓶頸

48,000 格合成道路測試在移入密集區後，原本約 16.2–16.6 FPS，CPU profile 大部分時間空閒。原道路 Image 使用 worldMask，串流地形 Blitter 卻無 Mask；兩者按深度交錯，反覆切換 stencil mask、打斷批次繪製。

地形 Blitter 現共用原道路／建築的同一個 worldMask，保留原投影、深度、素材及高度。單獨套用此修正的相同場景約 56 FPS；配合城市圖層快取後，最終測量約 60 FPS。這項修正不依賴減少地形細節。

## 測量範圍與結果

`npm run profile:world:loading`：Chrome 157 headless，1280×900，隔離瀏覽器資料庫，Service Worker 停用以記錄實際需求讀取；48,000 格合成道路只在測試記憶體中，渲染隔離場景暫停模擬。這不是實體 iPhone 或有大量人口／車輛城市的測量。

| 場景 | 平均 FPS | p95 幀時間 |
|---|---:|---:|
| 空城穩定畫面 | 59.8 | 16.8 ms |
| 八次跨區移動（含載入） | 60.0 | 16.8 ms |
| 48,000 格道路在遠處 | 60.0 | 16.8 ms |
| 鏡頭移入密集道路 | 60.0 | 16.8 ms |

此輪程式啟動約 3.79 秒，全境確認至詳細載入完成約 474 ms，期間平均 40.7 FPS，但仍有約 116.6 ms 的初次載入尖峰，不能解讀為每一幀都超過 30 FPS。密集道路場景持有 3,600 張道路圖片，低於九塊全部 9,216 格；未讀取完整 RLE。

維持最多九個詳細 Chunk、decoded terrain 2 MiB、pack 1 MiB、區域底圖 bitmap／texture 各 8 MiB、小地圖 bitmap 4 MiB。城市圖層額外使用固定 512×256 Canvas；已建資料及儲存成本仍隨實際建設增加，並沒有宣稱全部遊戲實體明細已做成分頁資料庫。
