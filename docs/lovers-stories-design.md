## 每局一次，分手最後

- 每篇在本城市最多刊登一次，紀錄存於 `city.loversStories.seen`；跟隨城市存檔及備份，新城市清空。
- 正常月結下，符合條件後有 25% 機會選一篇，兩次最少相隔 3 個遊戲月。麒麟賀歲等既有指定頭條保留優先權。沒有額外計時器或每幀重抽。
- 一定要成功加入新聞後先記錄。只符合條件、被抽到但讓位予指定頭條，或者新增新聞失敗，都不算已出過。
- 新聞歷史只保留最近 60 篇，刪走舊新聞不會清空故事紀錄；載入時亦會從舊存檔現存的海洋公園新聞補回紀錄。
- 分手篇不能跳過任何前置，包括未建設施／未遇到合適季節的篇章。刊登分手後，相簿結束，不重播日常或分手篇。
- 全部 10 段前置及分手篇在同一局完成後，立即觸發現有隱藏紀念勳章 D01《Claire的回憶》。授勳前勳章櫃仍隱藏名稱、條件及引言；授勳後沿用紀念章圖案，顯示名稱、引言與授勳紀錄。
- 故事進度按城市保存；完成事實與已取得勳章按玩家保存，換城市不會失去，也不會重複授勳。前置不能跨城市拼湊；單獨出現分手圖不算完成。載入已完整完成的故事存檔會補判勳章，即使新聞列已裁剪。
- 颱風及黃／紅／黑暴雨警告時暫停整組故事。普通雨天仍可出美術館、戲院或室內蟹宴；戶外場景須乾燥少風，山頂／星夜亦檢查清朗及污染。
- 使用中、英、日三語獨立文案；情侶故事不附加政府「密切留意」笑話，分手篇使用溫和留言，不附嘲笑反應。

## 圖片與驗證

原圖保留在故事板；`node scripts/prepare-lovers-story-images.js` 產生 10 張最多 1280 px 的 WebP 與 180×125 縮圖。既有海洋公園圖片繼續使用。大圖保留完整構圖，清單真正使用縮圖。作者故事板不進桌面／網頁執行包。

```sh
node --test test/lovers-stories.test.js test/forum-image-release.test.js
node scripts/smoke-lovers-stories.js
```

瀏覽器檢查使用隔離測試城市，逐篇經過實際月結新聞及討論區顯示路徑，覆蓋三語、大圖、縮圖及手機；預覽輸出至 `.data/lovers-story-review/`。
