# 手機巴士建造及營運（Phase C1）

基線：已發布 `v5.6.0`／`eb23cc9`。工作分支：`feature/mobile-bus-building`。手機仍為 Beta，沿用自動裝置選擇。呢批新增巴士站及車廠，其他交通／地形工具按原計劃逐批處理。

## 操作

- 「交通」直接提供巴士站／車廠；「建造 › 巴士」亦可進入。現有交通面板嘅「建車廠」問題提示會啟動同一個手機草稿。
- 巴士站：點直路，地圖顯示 A／B 兩側及步行覆蓋，選 A、B 或兩側，睇費用後確認。每新增一側 $20；單側互換及由兩側改成單側沿用桌面差額規則，沒有退款。單側站仍可加入路線，唔強制購買雙側。
- 車廠：點選 3×3 位置，「轉入口」切換四個方向，入口前方道路會標示接駁狀態。可先建未接路車廠，但買車及營運仍須入口接路。
- 點現有車廠可預覽免費轉向；顯示所屬車輛及路線數，取消不改方向。路面、舊建築、車隊指派或付款來源改變時，需要重新檢查預覽。
- 交通擴展未啟用／未解鎖時使用城市資金；啟用後只使用交通公司資金，不會以市庫補足。免費調整在公司負債時仍可使用。
- 確認、取消、微調、轉方向及失焦沿用建造草稿規則；只有確認可寫入城市。主指標 coarse 及載入 viewport 小於 1100px 仍會自動使用手機 Beta。

## 驗證方法

`test/mobile-bus-tools.test.js` 使用真實報價、付款及提交函式，覆蓋只讀預覽、兩個資金池、單次提交、資金不足、路面／付款來源／車隊變更、取消、佔位、邊界、方向、接路、免費調整及桌面原有四步巴士站循環。

`scripts/smoke-mobile-bus.js` 使用獨立 Chrome、全新城市及可存讀嘅住宅／圖書館乘客 fixture，透過手機 UI 起路、建站、建車廠、選站開線、買車及派車，再由實際模擬推進確認行駛、載客及車費，最後儲存及重開。覆蓋直橫向、三語排版、未確認旋轉取消、資金不足及失焦。

觸控自動化使用瀏覽器定時嘅 40ms 真實觸控手勢，避免 Node／CI 排程將原定 35ms 點擊拖成超過 300ms 嘅長按。遊戲本身嘅 300ms 點擊規則不變，並保留實際預覽／付款／城市結果檢查。

結果及截圖：`.data/mobile-bus/`（不入版控）。完整真機背景恢復、儲存鎖重取及跨裝置矩陣仍屬 Phase D 驗收，唔以模擬失焦代替真機簽核。

## 本輪結果（2026-11-12）

- `npm test`：1,277 項通過，沒有失敗或跳過；包括 11 項新增巴士工具測試。
- `CI=true node scripts/smoke-mobile-bus.js`：34 項通過，使用與 CI 相同嘅 Chromium 151。實際模擬行駛 206 格、載客 41 人、產生 $2.583 車費；市庫不受公司營運收支影響。
- `CI=true node scripts/smoke-mobile-build.js`：33 項原有建造及手勢檢查通過。
- `node scripts/smoke-mobile-panels.js`：38 項管理、路線選站、追蹤、直橫向三語排版及桌面還原檢查通過。
- 已目視檢查直向車廠、橫向巴士站及營運路線截圖；自動化瀏覽器沒有未捕捉錯誤。真機操作仍待 Norton 試玩。
