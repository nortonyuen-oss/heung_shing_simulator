# 原創地形：重寫程式生成器（5.1.0）

日期：2026-11-01。狀態：已接入遊戲（`terrain-original.js`），隨 5.1.0 推出。

## 1. 點解要重寫

5.0.0 嘅「香港實景」由真實地形抽取，夠真，但只可以出香港本身有嘅地形，而且有時認得出係邊度。「原創地形」用程式生成，每張都係新地圖，但要睇落似香港。

舊生成器（`terrain-generation.js` `generateRealisticTerrainMap`）嘅問題，用同一套指標同真實香港比較過：

| 問題 | 原因 |
|---|---|
| 45° 直線河道、直角轉彎 | `routeRiver()` 8 方向加慣性，慣性大過地勢 |
| 平頂山（L8 佔 8%–50%） | 高度超出上限就切平 |
| 平地喺內陸（距海 34–79 格，真實 15 格） | 冇侵蝕、冇沖積 |
| 海岸圓滑、海港長「手指」 | 只有低頻噪音 |
| 泥地圓點 3%–8% | `scatterDirtClusters` |
| 地圖邊懸崖 | 坡度規則之後先壓平地圖邊 |

## 2. 新做法（`generateOriginalTerrain(landform, seed)`）

1. **地貌輪廓**：每種地貌一個大形狀，決定陸地同海大致喺邊。海港 = 海由一邊入、越近出口越闊；半島 = 一條陸地伸出海；離島 = 3 至 6 個拉長、扭曲嘅島；谷地 = 兩邊山夾住一條谷底，水只會由一端海入；山邊 = 由一邊升高；平原 = 大片低地，一邊有山。
2. **山脊**：脊狀多重分形噪音（ridged multifractal），加 domain warp 令山脊彎曲分叉；山脊距離約 1 至 1.5 公里。
3. **海岸細節**：多層噪音令海岸有大小不一嘅灣同岬角。
4. **水力侵蝕**：模擬 45,000 粒水滴落山，沖出樹枝狀山谷，泥沙沉積填平谷底同海邊，平地自然出現喺啱嘅位置。
5. **海平面**：按地貌喺真實水域比例範圍（第 10 至 90 百分位）入面隨機揀，再切；只保留連住地圖邊嘅海，內陸低窪變平地（香港冇天然湖）。
6. **高度分級**：陸地按高低排序，再對應真實香港嗰種地貌嘅高度分佈（L0 至 L8 各佔幾多），由香港實景窗口量度得出（`ORIGINAL_TERRAIN_TARGETS`）。
7. **沙灘**：坡度緩、高度 0 嘅海岸，一段段咁出現。
8. **整理**：用地區地圖同一套規則（`finishHkTerrain`）；唔壓平地圖邊，唔撒泥地，唔畫河。

## 4. 已完成

1. **海港形狀**：入口越近出口越闊，加大尺度噪音整出側灣、海峽同小島。
2. **水域比例**：喺真實範圍入面抽，但偏向真實中位數（平原幾乎乾、海港分佈較闊）。
3. **速度**：侵蝕改為 24,000 粒水滴、筆刷半徑 2、每步唔建立物件。
4. **介面**：「隨機生成」分「香港實景」同「原創地形」兩個模式，共用同一排地貌選項。
5. **取代舊生成器**：預設隨機地圖、地圖編輯器重新生成、測試 script 全部改用新生成器；舊生成器（1,400 行，沙漠、高原等）連同舊城市場景（東京、紐約等，Google Earth 海岸線遮罩）一併刪除。舊存檔或者舊「我的地圖」記錄嘅地貌名（例如 `island`）會對應到最接近嘅新地貌。
6. **測試**：`test/terrain-original.test.js`：每種地貌嘅水域喺真實範圍、冇泥地、冇懸崖、冇平頂山、同一種子出同一張地圖。

## 5. 已決定（Norton，2026-11-01）

1. 「隨機生成」分「香港實景／原創地形」兩個模式，共用地貌選項。
2. 舊生成器同沙漠、高原等地貌一併刪除。
3. 維園選單修正唔單獨出 5.0.1，同 5.1.0 一齊出。
