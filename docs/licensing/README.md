# 香城模擬器：授權方案與盤點

盤點日期：2026-09-15；專案版本：4.9.0。方向已由開發者確認：保留程式與原創素材的商業權利。

## 建議採用的架構

採用專有遊戲授權，分開管理遊戲程式、素材、玩家分享與第三方元件。免費提供遊玩，不等於開源；公開原始碼也不代表允許別人拿去改作、重製或販售。

| 層次 | 建議規則 |
| --- | --- |
| 自有程式、文字、介面與可受保護的美術成果 | 保留權利；只授予執行、備份及明確列出的玩家使用權 |
| 官方遊戲下載 | 可免費遊玩；新版本的再散布採官方連結優先，鏡像與重新上架需另外授權 |
| 截圖、攻略、實況、影片 | 容許介紹與評論，包括創作者營利；音樂等第三方內容必須另外符合其條款 |
| 第三方套件、Kenney 原始素材、政府資料 | 各自依原授權；遊戲條款不能取消其原有權利 |
| 品牌與標誌 | 保留權利，容許識別遊戲所需的合理使用，不授權冒充官方 |
| 未來貢獻、委外、移植與商店發行 | 以明確書面權利紀錄支援，不因接受 PR 或付款就假定取得所有權 |

不建議把整個 repository 套上 MIT、GPL 或 CC BY-NC：前兩者容許符合條件的商業利用，後者不適合作為軟體授權，也不能處理本專案各種不同的第三方權利。

## 目前結論

可以先確立「保留商業權利」的遊戲條款，但**現有素材尚不能全部認定已取得商業發行與玩家轉授權所需的權利**。首要項目是 Suno 免費方案的九首音樂，以及尚未辨明資料集的 Google 海岸線來源；天文台年曆衍生資料也要另行處理。

2026-09-15 已依開發者指示採用根目錄 `LICENSE` v1.0，以 GitHub 公開身份 `nortonyuen-oss` 署名；官網版權頁提供四種語言摘要及同一正式全文。條款只適用於包含它的新原始碼版本／發行包，不溯及撤銷已有效授予的舊版權利。第三方素材缺口仍保持待查，正式遊戲授權不替代第三方許可。

這是依專案檔案、開發者陳述及官方條款做的授權設計；商業發行前，宜由熟悉主要發行地的法律專業人士確認未決來源、AI 成果保護範圍及條款效力。
