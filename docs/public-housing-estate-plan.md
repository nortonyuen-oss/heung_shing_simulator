# 公屋／居屋屋邨規劃：配置方程式（設計稿，2026-11-24）

一句講晒：**劃一塊公屋或居屋地，遊戲一次過替成塊地規劃好一個屋邨。** 每一格預先分好用途：

- 邊幾格起樓
- 邊幾格做公園
- 邊度預留社區中心、街市同球場

樓宇一座一座咁入伙，但唔會再有起唔到樓嘅 1x1 空格。

計法可以直接試：`node scripts/estate-layout-preview.js 10x6 public 2`（印出一塊地嘅規劃），`--table` 印總表。下面所有圖同表都由呢個 script 生成。

---

## 1. 而家點解會卡住 1x1 空位

公屋區、居屋區只會生標咗類型嘅美術（`housing-types.js`），而呢啲美術得幾種大小：

| 類型 | 有嘅地盤大小 | 最細 |
|---|---|---|
| 公屋 | 2x2（安樂邨矮座）、3x3（Y型、和諧式、舊長型）、8x8（安泰邨成邨） | 2x2 |
| 居屋 | 3x3（居屋 HOS）、4x4（安泰苑、十字型） | 3x3 |

生長係逐格咁揀：每格試「放得落嘅最大款」（`sim-growth.js` `chooseHousingEstateFootprint`），完全唔理成塊地點樣分。所以放完大座之後，剩低嘅窄條就冇款放得落：

- 公屋 4x4：放咗一座 3x3，剩一條 1 格闊嘅 L 形，7 格（44%）永遠空。
- 居屋 6x6：放咗一座 4x4，剩一條 2 格闊嘅 L 形，20 格（56%）永遠空，因為居屋最細都要 3x3。

**根本問題係逐格揀，唔係成塊地規劃。** 香港房委會都係成個屋邨一齊規劃，所以解決方法係照佢咁做。

## 2. 設計藍本：香港屋邨嘅結構

- **同邨同款**：一個屋邨用同一款標準設計樓宇，視乎年代：
  - 60 年代長型
  - 70 年代雙塔式
  - 80 年代 Y 型
  - 90 年代和諧式（十字形，約 40 層）
  - 2000 年起逐步改用因地制宜嘅非標準設計，最後一個標準設計屋邨係 2009 年嘅秀茂坪南邨

  居屋苑亦一樣，一個苑通常幾座同款。

  遊戲只跟「同邨同款」，唔跟年代：幾款輪住用（§3.10）。
- **樓距**：座與座之間要留空間採光通風。座之間嘅空地就係屋邨嘅園景、遊樂場、休憩處。
- **中央休憩用地**：較大嘅屋邨中間有中央公園／廣場，各座圍住佢。
- **前路有設施**：街市、商場同巴士站喺近大路嘅一邊（屋邨入口）。社區會堂、球場喺屋邨入面。
- **規劃標準（HKPSG）**：休憩用地每人最少 2 m²，其中地區休憩用地 1 m²、**鄰舍（本地）休憩用地 1 m²**。屋邨地盤要照顧到嘅係後者。
- 社區會堂喺規劃標準入面「冇固定比例」，由房委會按屋邨大細安排。所以設施門檻（§3.4）係遊戲設定，按座數計。
- **居屋苑比屋邨細**（幾座至十幾座），一般冇街市（只有基座商舖），以平台花園為主，空地比例可以低少少。

**遊戲比例**：一格 20 m（`docs/world-scale.md`），即一格 400 m²。和諧式一座約 40–45 m 闊，即約 2 格，再加樓下平台／園景，就係而家 3x3 地盤美術嘅樣。

## 3. 方程式

符號：

- 地盤 **W x D**：W 係沿前路嘅闊度，D 係深度。
- **t**：座闊（公屋 3；居屋 4 或 3，見 §3.6）。
- **前路**：地盤邊有最多馬路嗰邊，見 §6.2。

### 3.1 一行放幾多座：n(W)

座與座之間留 1 格樓距：

```
n = floor((W + 1) / (t + 1))
s = W - (n·(t + 1) - 1)          ← 剩低嘅格數（0 ≤ s ≤ t）
若 s = t：n = n + 1，s = 0        ← 啱啱剩一座闊：兩座「相連」，中間冇樓距
```

- 剩低嘅 s 格撥去**中間嗰條樓距**，令佢變闊做庭園。前後幾行都撥去同一位置，所以上下對齊，變成一條貫通嘅中庭。
- 一座都放唔落（W < t）：成行做園景。

例子（公屋 t = 3）：

| W | 座數 | 排法（座 / 空） |
|---|---|---|
| 3 | 1 | 3 |
| 4 | 1 | 3 / 1 |
| 6 | 2 | 3 3（相連） |
| 7 | 2 | 3 / 1 / 3 |
| 10 | 3 | 3 3（相連）/ 1 / 3 |
| 11 | 3 | 3 / 1 / 3 / 1 / 3 |

最「慳位」嘅闊度係 W = 3、6、7、10、11、14、15…（s = 0）。教學提示用得著（§7）。

### 3.2 深度分帶：B(D)

由前路向入面，將 D 切成幾條「帶」：

- **T**：樓帶（深 t）
- **G1**：1 格園景帶（有蓋行人道＋樹）
- **S2**：2 格服務帶（公屋放 2x2 矮座，居屋做公園）
- **C3／C4**：屋邨中庭（中央公園＋設施）

公屋（t = 3）：

| D | 分帶 |
|---|---|
| 1 | G1 |
| 2 | S2 |
| 3 | T |
| 4 | T G1 |
| 5 | T S2 |
| 6 | T T（背靠背） |
| 7 | T G1 T |
| 8 | T S2 T |
| 9 | T C3 T |
| 10 | T C4 T |
| ≥ 11 | T G1 ＋ B(D − 4) |

居屋（t = 4）：

| D | 分帶 |
|---|---|
| 3 | T3（用 3x3 款） |
| 4 | T |
| 5 | T G1 |
| 6 | T S2 |
| 7 | T T3 |
| 8 | T T |

| 10 | T S2 T |

| 12 | T C4 T |
| ≥ 13 | T G1 ＋ B(D − 5) |

每條樓帶用 §3.1 排座。S2 帶用同一條式（t = 2）排矮座。

### 3.3 休憩用地要求（不足就讓出中間嗰座）

有 3 座或以上嘅屋邨，空地要同時達到兩個要求：

```
空地格數 ≥ max( ceil(r × W × D),  ceil(人口 / 400) )
r = 0.20（公屋）／0.15（居屋）
人口 / 400 = HKPSG 每人 1 m² 鄰舍休憩用地（一格 400 m²）
```

未達標：拆走**最近地盤中心嗰座**，讓出嚟做中央公園，再計一次，直至達標。1–2 座嘅小地盤（插針樓）唔使計。

### 3.4 設施配額（按規劃座數 N）

| 設施 | 公屋 | 居屋 | 遊戲建築 |
|---|---|---|---|
| 社區中心 | N ≥ 4 一間（N ≥ 16 兩間） | N ≥ 6 一間 | `community_centre` 2x2 |
| 街市 | N ≥ 6 一個 | 冇 | `public_market` 2x2 |
| 球場 | N ≥ 8 一個 | N ≥ 8 一個 | `sports_ground_small` 2x2 |

N 用 §3.3 之前嘅座數，即係「呢塊地本來規劃得幾多座」。

### 3.5 設施放邊

每個設施喺空地揀分數最低嘅 2x2：

```
街市：     行號 × 10 + |列 − 中線|      ← 貼住前路、近中間（屋邨入口）
社區中心： 同地盤中心嘅距離              ← 屋邨正中
球場：     −行號 × 10 + |列 − 中線|     ← 最入面、近中間
```

空地冇 2x2 位：街市同社區中心會讓出分數最低嗰座（即係最近前路／中心嗰座）。球場就唔起，唔會為佢拆樓。

### 3.6 居屋揀座型

居屋用 4x4（安泰苑、十字型）同 3x3（居屋 HOS）各規劃一次：

- 3x3 嗰個方案住多過 25% 人，就用 3x3。
- 否則用 4x4（苑嘅樣）。

### 3.7 公園填充（零空格）

設施放好之後，剩低嘅空地依次放：

1. 一個 **3x3 大公園**（`large_park`），放喺最近中心嘅 3x3 空位。
2. 所有 **2x2** 空位：第一個係**籃球場**（`sports_ground_small`，香港屋邨籃球場圖），之後籃球場同 `palm_court` 花園輪住用。（Norton，2026-11-24：籃球場比雕像廣場更似香港屋邨。）
3. 剩低每一格：**1x1**，按位置揀款：
   - 貼住前路：`plaza_square`（入口廣場）
   - 喺座與座之間：`playground` 同 `garden_plaza` 輪住（兒童遊樂場／樓下花園）
   - 其他：`open_ground`（休憩處／長者健身）

### 3.9 零空格保證

- 分帶將 D 切盡。
- 每條帶入面，§3.1 將 W 切盡：座、樓距、剩餘都有歸屬。
- 所有唔係樓、唔係設施嘅格，最後都由 §3.7 填 1x1 公園；1x1 永遠放得落。

所以**任何 W x D 都冇空格**。

### 3.10 同邨同款（唔分年份）

一個屋邨所有座用同一款，但**唔按年份揀**（Norton，2026-11-24：遊戲好難玩到 90 年代，而且而家貼圖唔夠，按年代分會令成個城市得一款）。每個新屋邨揀**而家最少屋邨用緊**嗰款，同樣少就輪住揀，所以城市入面幾款混住：

| 類型 | 輪住用嘅款 |
|---|---|
| 公屋 3x3 | 和諧式 `residential3-02-L-MD`、Y型 `residential3-01-L-MD`、舊長型 `residential3-06-L-MD` |
| 居屋 4x4 | 安泰苑 `residential3-07-M-MD`、十字型 `residential3-08-M-MD` |
| 居屋 3x3 | 居屋 HOS `residential3-14-M-MD`（得一款） |
| 公屋矮座 2x2 | `residential2-04-L-MD`（得一款） |

以後有新圖（例如雙塔式、非標準設計），加入呢張表就會多一款輪住用。

### 3.11 斜坡：分層平台（Norton，2026-11-24 問）

香港山邊屋邨（例如秀茂坪、慈雲山）係分層平台起：每層平台平地起樓，層與層之間係綠化斜坡。

- **斜坡格**本身唔可以起嘢（遊戲本身規則），所以唔會劃入屋邨。
- 地盤按**高度**切開：每個長方形只可以喺同一高度，即係每層平台各自用 §3.1–§3.9 規劃。冇一座樓、冇一個公園會橫跨兩個高度（否則嗰座永遠起唔到）。
- **設施**計成個屋邨：用全部平台加埋嘅座數計配額（§3.4），放喺最大嗰層平台；唔會每層各有一個街市。
- **斜坡綠化**：地盤入面嘅斜坡格，喺第一座入伙鋪園景嗰陣種樹。

## 6. 點樣接入遊戲

### 6.1 資料

```js
city.housingEstates = {
  'estate-1': {
    id, type: 'public' | 'hos', name: '安X邨',   // 名：區名／自選字 + 邨（公屋）或 苑（居屋）
    rect: { row, col, w, d }, front: 'n' | 'e' | 's' | 'w', model: 'residential3-02-L-MD',
    slots: [{ kind: 'block' | 'low' | 'market' | 'centre' | 'sports' | 'park3' | 'park2' | 'park1',
              row, col, size, variant, label: 'A', built: false }],
  },
};
```

- 每格仍然係公屋／居屋分區（`city.housingZones` 照舊），規劃屬於分區上面一層。
- `city-state.js` 要加白名單，重設時清走。

### 6.2 劃地

- 拖一個公屋／居屋長方形，就係一個屋邨（房委會都係一邨一邨咁建）。
- 拖嘅時候即時預覽：樓位、公園、設施位置，加一行摘要（§7）。
- **前路**：長方形四邊之中，貼住最多馬路嗰邊。如果冇一邊貼馬路，就揀最近馬路嗰邊。
- 規劃喺「前路喺 row 0」嘅本地座標計，然後轉向放落地圖。
- **地盤入面有障礙**（已有建築、水、唔平嘅地）：
  - 只用可以分區嘅格，切成最大嘅幾個長方形，每個 ≥ 3x3 嘅各自規劃。
  - 剩低嘅窄條照 §3.2 處理：1 格闊做園景，2 格闊做矮座或者 2x2 公園。
  - 唔平嘅樓位就改做公園。

### 6.3 生長：分期入伙

- 唔再逐格揀。每個月有住宅需求，就喺每個屋邨起下一座未起嘅樓位，次序係近前路嗰行先、近中線先（一期、二期）。
- 用嗰個屋邨揀定嘅款（§3.10）。
- 升降級保持地盤大細：而家 `getHousingEstateLotOverride` 已經係咁做。
- 拆咗一座：樓位留返，之後再起。
- 取消分區：成個規劃取消，已起嘅公園同設施留低。

### 6.4 公園同設施

詳細選擇見 §9：

- **公園**：建議第一座入伙嗰陣一次過鋪好，費用計入分區費。屋邨嘅園景係房委會一齊起嘅。
- **社區中心、街市、球場**：建議做「預留地」。地圖上見到虛線框同圖示，座數到咗門檻，就喺屋邨資料出一粒「起社區中心（$1,800）」掣。
  - 呢幾樣有起樓費同月費，所以交返玩家決定。
  - 未起之前，預留地顯示成草地，唔會係空地。

### 6.5 舊存檔

- 已有嘅公屋／居屋區冇規劃，照舊逐格生長。
- 另外加一條「**空格綠化**」規則：分區入面空咗 6 個月、又放唔落最細款嘅格，自動變 1x1 休憩處。呢條即使唔做成個規劃器都可以先出，即刻解決卡位問題。
- 屋邨資料加一粒「重新規劃」：將未起樓嘅空地照 §3 規劃。

### 6.6 手機

- 手機用同一個預覽，即 build-session 嘅草稿預覽。
- 摘要寫喺 `#mobile-build-status`。

## 7. 教學

**劃地時嘅預覽摘要**（電腦同手機都有）：

> 公屋 · 10x6 · 4 座和諧式（約 2,700 人）· 街市、社區中心 · 休憩用地 16 格（每人 2.4 m²，香港標準 1 m²）
> 💡 再深 1 格（10x7）可以多起 1 座。

「再闊／深 1 格可以多 1 座」嘅提示：喺 W ± 1、D ± 1 各試一次 §3，邊個座數多就提示邊個。

**第一次揀公屋區／居屋區**：出一張一次性提示卡，四點：

1. 一塊地就係一個屋邨，遊戲會幫你規劃。
2. 闊 7 或 10、深 6 或 7 最好用：例如 10x6 有 4 座、街市、社區中心。
3. 4 座有社區中心，6 座有街市（居屋 6 座有社區中心，冇街市）。
4. 公園唔係浪費：香港規劃標準每人要有 1 m² 休憩用地；唔夠嘅話，中間嗰座會讓出嚟做公園。

**第 5 章黃大仙《有求必應》**：任務卡提示由「住宅分區揀公屋區或居屋區」改成：

> 揀「公屋區」拖一塊 10x6 左右嘅地，遊戲會規劃成一個屋邨。

開局再加一句秘書：

> 房委會起屋邨，係成個邨一齊規劃㗎。

**屋邨資料**（撳屋邨任何一格）：

- 邨名
- A座、B座…，每座入伙狀態
- 設施（已起／預留）
- 休憩用地每人 m²

## 8. 美術（可以之後補）

而家嘅圖已經夠用。以下係補咗會更似：

- 公屋 3x3：**雙塔式**、**非標準設計**；舊長型可以多一款。有新圖就加入 §3.10 嘅輪住表。
- 居屋 3x3：多一款，而家得「居屋 HOS」一款，佢 spawnWeight 只有 0.25，因為睇落似 2x2。
- 屋邨 3x3 **商場＋街市**（取代 2x2 街市喺大屋邨用），同**屋邨巴士總站**。
- 安泰邨 8x8 成邨圖：建議唔入規劃器，留俾「整邨」選項用（見 §9）。

## 9. 已決定（Norton，2026-11-24）

1. **公園收費**：計入分區費，第一座入伙一次過鋪（每格園景 $100）。庫房唔夠錢就等第一座入伙先收。
2. **設施點起**：預留地，入伙過半就喺屋邨資料出掣，由玩家起。未起之前預留地係草地。
3. **一個屋邨＝一次拖**。
4. **安泰邨 8x8 成邨圖**：啱啱 8x8 嘅公屋地盤用佢。
5. **舊存檔**：空格綠化。屋邨以外嘅公屋／居屋格，空咗 6 個月、又永遠放唔落一座，就變 1x1 休憩處。

另外：**第 1 章只開放私人住宅**，等玩家先熟悉遊戲世界觀；公屋區、居屋區由第 2 章起開放。
