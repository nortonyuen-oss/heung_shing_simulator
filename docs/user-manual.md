## 分區自然生成模型

香城嘅住宅同商業建築出現比例，向香港真實嘅房屋政策睇齊：公共／大眾房屋（L）喺中高密度區為大宗，私人物業（M）為次要，豪宅／甲級寫字樓（H）係真正嘅少數，UH（豪宅莊園、匯豐總行、中銀大廈呢類地標）維持極稀有。L／M 沒有額外硬性門檻，按地段質素及以下權重生成；H／UH 除權重外仲要另外通過資格門檻，兩者都係逐個地段評估，並非「全城一次性解鎖」。

### 資格門檻

| 模型級別 | 出現條件 | 機制 |
| --- | --- | --- |
| 科學園 | 高等教育指數至少 0.80；工業建築 footprint 至少 2×2 | 可由新工業發展或現有工業轉型；「科研發展法」提高機率，但不是硬性條件 |
| H 富人住宅 | 綜合質素 0.60、地價 0.50、環境 0.45、健康 0.45、經濟 0.45 | 所有住宅密度均可能出現，受附近 H／UH 密度抑制 |

### 低密度規劃永久鎖定

一幅地一經玩家劃為低密度住宅，就會被永久記錄為低密度地——之後無論點樣 dezone、拆卸重建，都唔可以再改劃做中／高密度住宅，確保低密度區永遠保持村屋、祠堂、別墅嘅低層風貌。呢個限制只單向生效（低密度唔可以升，中／高密度之間就冇呢個限制），亦唔影響商業或工業分區。喺呢個功能推出之前已經存在嘅存檔，讀取時會自動追溯鎖定現有嘅低密度地。

## 解鎖通知

城市第一次達成一項離散解鎖條件時，走馬燈及香城討論區會刊登一次通知。通知涵蓋人口、城市吸引力、法案、議會項目、高等教育、立法會、股票交易所及科學園解鎖。通知狀態會寫入存檔，避免每月重複播放；已經存在的建築亦會自動視為已通知。
