# 手機日常建造工具（Phase C2）

基線：C1／`6cdcde6`。工作分支：`feature/mobile-daily-tools`。手機仍為 Beta，沿用 coarse pointer 及載入 viewport 小於 1100px 自動選擇；直向、橫向均有相同功能。

## 操作及付款

- 電力水務 › 電線：點 A／B 決定直線，顯示有效格、跳過格及清樹數，每個新格 $5；現有線及水面不收費。確認後沿用 `placePowerLine`，標記供電網絡重算並即時更新。
- 康文署 › 樹木：兩角矩形，按原有種樹規則排除道路、水面、建築、現有樹、電線及地區牌；空分區及路旁可種，每格 $15。預覽、微調、縮放、取消均不種樹／扣錢。
- 城規會 › 取消分區：兩角矩形，只清除分區，顯示保留嘅建築數；免費，即使市庫負債亦可使用。建築、人口、永久低密度指定均保留。
- 康文署 › 公園／運動場：明確款式選單，顯示款名、佔地及費用；公園 10 款、運動場 2 款。維園保留原有六模組循環；其他公園改變下一模組時，原草稿須重新確認。棕櫚苑沿用選單標價 $500，修正舊 writer 只扣 $250 嘅差異；桌面、手機共用同一報價及 writer。
- 地圖 › 地區牌：先揀地格，設定中英文名，再確認 $250 放置。中文最多 30 字元、英文最多 48 字元；沿用修剪、英文空白合併、中文名稱唯一及全城 16 牌限制。取消任何名稱對話框或建造草稿均不付款。
- 查詢模式點地區牌／其地格可免費修改中英文名。手機牌面不再於 `pointerdown` 直接開對話框，只在完成單點後改名；指向牌面開始雙指／平移不觸發改名。異步輸入期間切換城市或取消草稿，不會寫入新城市。

建造全用市庫，巴士交通公司資金規則維持 C1 行為。範圍工具共用起終點及微調判斷，確認時重驗整筆資金、佔位、現有設施及公園模組；草稿 ID 只能提交一次。

## 驗證

`test/mobile-daily-tools.test.js` 使用真實報價、範圍、植樹、分區、地區牌及建造 writer，只有圖形繪製 stub；包含只讀預覽、單次付款、即時標記供電、資金不足、變更後重驗、範圍端點、公園／運動場全部款式、地圖邊界、取消、名稱限制及跨城市異步防護。

`scripts/smoke-mobile-daily.js` 使用獨立瀏覽器及全新城市，以 40ms 瀏覽器定時觸控操作六個工具；確認電線令原本未接駁嘅圖書館即時有電，驗證公園模組、雙語牌面改名、直橫向三語長字排版，最後存檔重開比較樹木、電線、清除分區、低密度鎖、建築款式及中英文名。

存讀檔比較逐格保留樹木位置、品種、年齡、隨機外觀、數量及人工種植標記；按 compact save 規格將省略嘅 `count` 視為 1、`planted` 視為 false，唔將載入時補回預設欄位誤判為資料變更。

結果及截圖保存在 `.data/mobile-daily/`（不入版控）。真機效能、系統鍵盤／背景恢復、儲存鎖重取及跨裝置測試仍屬 Phase D，唔以桌面觸控模擬代替真機驗收。
