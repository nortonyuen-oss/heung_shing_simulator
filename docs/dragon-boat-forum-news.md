# 龍舟競渡：香城討論區新聞稿

2026-10-11。狀態：稿件及觸發設計，未接入 runtime。
配合 `dragon-boat-racing-design.md`。以下 `{…}` 由當屆賽事資料填入，唔係固定城市、名次或日期。

## 發稿方式

作者「香城日報」、分類「城中熱話」、`source: 'local'`。正文用新聞語氣，留言用廣東話街坊語氣；荒誕度上限 2。

本屆六隊固定為「{districtName}街坊福利會」「香城女神隊」（綠色、女性鼓手）「李彩樺漁業聯會」「漁民樂海鮮酒家」「香城討論區毒L」「{transportCompanyName}小輪職工會」。公司未成立／冇名稱時用城市名稱；區域、公司及隊名沿用當屆快照。

賽事指定贊助商為薩利亞意式餐廳。正常開賽／完成稿末段加入「本次香城龍舟邀請賽由薩利亞意式餐廳贊助。」；正文保持賽果為主，廣告輪播文案見競渡設計 §8.1。取消／中止稿優先交代原因，唔加食飯促銷。

每屆一篇主要論壇帖：完成就出賽果，取消／中止就出該分支；冇場地或冇錢則出未能舉辦稿。開賽、延期、決賽預告先用通知及跑馬燈，唔每個階段都洗版。開賽稿仍準備好，日後需要賽前專帖可以直接用。

固定 post id：`festival-dragonBoat-{year}-{month}-report`。互斥嘅年度終局稿只出一次；讀檔唔重發。現有 `addForumPost` 遇同 id 只返回舊帖，唔會更新正文，所以唔用同 id 先發開賽再當作已更新賽果。

正常完成稿優先：爆冷 → 險勝 → 一般完成；同時符合時正文可以補一句實際時間差，標題只選一個版本。

## 1. 開賽稿／通知文案

**標題：** 【鼓聲響起】{cityName}龍舟邀請賽開鑼　六隊喺{venueName}對開海面爭標

**正文：**

今年{cityName}龍舟邀請賽於{venueName}對開海面舉行，{teamList}六支隊伍將沿{distanceM}米水道競逐城市盃。龍舟分別以紅、黃、綠、藍、紫、黑六色亮相，各隊完成集結後，按線道準備起步。

賽事安排兩輪排位賽，再由六隊進行決賽。決賽預定於下午{finalStart}開始，冠亞季軍將按龍舟最前端通過終點嘅時間決定。岸邊設有看台、大會台及頒獎區，市民可沿海濱步道觀看比賽。

**留言範本：**

- 海旁阿叔：「龍舟一出嚟就知端午到，隻鼓一響個人都精神晒。」
- 睇船唔睇粽：「六隻色好易認，我撐{supportedTeam}！」
- 街坊運動迷：「先睇排位，決賽先係真章。」

延期後開賽用一輪排位時，第二段須改成「賽程縮減為一輪排位賽及決賽」，唔套正常兩輪稿。

## 2. 一般完成：年度主稿

**標題：** 【端午爭標】{champion}勇奪{cityName}龍舟盃　{runnerUp}、{thirdPlace}分列亞季軍

**正文：**

{cityName}龍舟邀請賽今日喺{venueName}對開海面完成。六支隊伍沿{distanceM}米水道同場競渡，經過{qualifyingRounds}輪排位賽及決賽，{champion}最終率先衝線，以{championTime}奪得城市盃；{runnerUp}同{thirdPlace}分別獲得亞軍及季軍。

各隊衝線後減速離開競賽線道，返回浮台。大會其後公布正式名次，並於海旁頒獎區頒發獎項。今年城市盃冠軍由決賽成績決定，排位賽只用作安排決賽線道。

**成績附表：** 六隊名次、隊色及決賽時間；只列完成決賽嘅正式結果。時間差以未四捨五入嘅內部用時計算，再格式化顯示。

**留言範本：**

- 鼓聲未停：「恭喜{champion}！今年個盃帶返去啦。」
- {runnerUp}街坊：「有亞軍已經好勁，下年再嚟！」
- 食粽專員：「我負責食粽，佢哋負責爭氣。」
- 海旁攝影友：「六條船一齊起步嗰下最靚。」

唔自動加「破紀錄」「歷屆最多人」「全城交通癱瘓」或傷亡數字。冇量度觀眾人數就唔寫幾萬人；未接運輸需求亦唔寫巴士公司加班或收入暴增。

## 3. 爆冷奪冠變體

**觸發：** {champion}嘅排位總榜名次 ≥4，而決賽正式第一。呢個係遊戲新聞門檻。

**標題：** 【爆冷捧盃】排位第{qualifyingRank}照樣贏！{champion}決賽奪冠　街坊：最緊要最後嗰場

**首段替換：**

今年{cityName}龍舟邀請賽出現爆冷賽果！兩輪排位賽總榜排第{qualifyingRank}嘅{champion}，喺{venueName}對開海面舉行嘅{distanceM}米決賽以{championTime}率先衝線，擊敗其餘五隊奪得城市盃。{runnerUp}同{thirdPlace}分列亞季軍。

其餘段落用一般完成稿。延期只得一輪時，「兩輪排位賽總榜」改成「排位賽」。唔聲稱「落後反勝」，除非速度曲線真係有對應超前紀錄。

**留言：** 「排位唔係決賽，隻盃識揀最後先發力嘅人。」／「{champion}街坊今晚有排講。」

## 4. 險勝變體

**觸發：** 決賽第一、第二嘅內部時間差 >0 且 ≤0.5 秒。標題必須用足夠精度顯示差距；唔將正差距四捨五入成 0 秒。

**標題：** 【爭到最後】只差{finishGap}秒！{champion}險勝{runnerUp}　龍鼻先過線捧盃

**首段替換：**

{cityName}龍舟邀請賽決賽鬥到最後一刻。{champion}同{runnerUp}沿{venueName}對開嘅{distanceM}米水道完成比賽，最終{champion}以{championTime}率先通過終點，僅以{finishGap}秒差距奪冠。{runnerUp}屈居亞軍，{thirdPlace}取得季軍。

**留言：** 「真係睇個龍鼻！」／「{runnerUp}都好勁，下年再爭。」

完全同時嘅內部結果按排位決勝時，唔用險勝稿；一般稿明確寫「完成時間相同，按排位成績決定名次」。

## 5. 延期通知

**標題：** 【天氣有變】{venueName}龍舟賽延至上午10點再作安排　六隊暫留集結區

**正文：**

受{weatherReason}影響，今年{cityName}龍舟邀請賽暫緩派船。大會將於上午10點按天氣情況決定是否開賽；如恢復比賽，賽程會縮減為一輪排位賽及決賽。

目前尚未產生正式賽果，原定決賽及頒獎安排須以更新通知為準。

`weatherReason` 取事件發生時快照，例如「三號強風信號」或「紅色暴雨警告」，唔用發稿當下天氣覆寫舊原因。此稿作短通知／跑馬燈，年度論壇帖留待終局。

## 6. 未開賽取消：年度主稿

**標題：** 【未能下水】{weatherReason}未退　{cityName}本屆龍舟邀請賽取消

**正文：**

今年{cityName}龍舟邀請賽原定於{venueName}對開海面舉行，早上因{weatherReason}延期。至上午10點，天氣仍未符合開賽條件，大會宣布取消本屆日間賽事。

六隊未進行正式決賽，今年唔會頒發城市盃。已搭建嘅場地將按安排清理；本屆籌辦費用及退款記錄已更新至節慶年曆。

**留言：** 「等下年，個盃唔會走。」／「粽照食，船等好天先扒。」

只喺真係經歷 06:00 延期 → 10:00 取消時用呢個版本；其他時點直接取消應改寫時間敘述。

## 7. 賽事中止：年度主稿

**標題：** 【決賽未完成】{cityName}龍舟盃因{stopReason}中止　本屆不設冠軍

**正文：**

喺{venueName}對開海面舉行嘅{cityName}龍舟邀請賽，於{stoppedAt}因{stopReason}中止。大會停止餘下賽程，唔會以未完成嘅決賽或排位榜頒發冠軍。

{completedRoundsText}。本屆結果以「中止」記錄，費用及退款按已完成階段處理。

`stopReason` 係天氣事件／水道被佔用／主會場失效等已發生原因；`completedRoundsText` 按真實已完成輪數寫。場地失效唔一定有正常返航，因此唔一律加「所有船安全返回浮台」。正式決賽已完成後先變天則維持冠軍，只寫頒獎／清場安排有變。

## 8. 冇場地／資金不足

**冇場地標題：** 【海旁未夠位】{cityName}本屆未能舉辦龍舟盃　欠合格競賽水道

**正文：** 今年{cityName}未能找到同時符合觀賽步道、直線水道及船隻通道要求嘅主會場，本屆龍舟邀請賽未能舉行。相連海濱步道並唔等於有足夠海面作賽；今年未收取籌辦費，亦冇產生賽果。

**資金不足標題：** 【籌辦費未落實】{cityName}本屆龍舟盃未能開賽

**正文：** 本屆龍舟邀請賽因城市未能支付所選規模嘅籌辦費而未能舉行。節慶年曆可調整下屆規模，今年冇正式賽果。

玩家主動揀「唔辦」／關閉活動唔出責備政府嘅未能舉辦帖；只記設定及必要結算。

## 9. 圖片同「薩利亞」預留

已有 `UI/news/薩利亞！龍舟激撞現場.png`，圖中文字明確描繪兩舟碰撞。正常開賽、奪冠或天氣取消稿唔用呢張圖。

日後有真實碰撞事件先新增彩蛋稿「【薩利亞！】龍舟賽突發擦碰　海旁阿叔一句嗌響討論區」，正文必須由事件提供涉及隊伍、影響、裁判處理及最終賽果。若冇人物受傷紀錄，唔自動寫「無人受傷」；未有拍攝／觀眾事件就唔聲稱片段瘋傳。首版競渡設計冇碰撞機制，所以呢篇同圖先預留。

正常比賽需要一張六船競渡／海旁頒獎新聞圖，或者實際遊戲截圖；圖片未準備好可發純文字帖，唔阻擋結果發佈。新圖片轉為 WebP 後先進 release；目前正常新聞圖尚未製作。

## 11. 欄位及接入

引擎提供 `festival_event`：`cityName`、`year`、`month`、`venueName`、`distanceM`、`teamList`、`qualifyingRounds`、排位榜、決賽名次／內部時間、已完成輪數、當屆狀態、天氣／中止原因快照、退款及已發稿旗標。

顯示日期沿用遊戲年月，唔寫開發時嘅真實日期。未知場地唔作具名敘述，缺決賽資料唔生成冠軍稿。稿件唔依賴雲端 AI；有 AI 時只改寫語氣及留言，唔改名次、隊名、距離、退款或取消原因。

`social.comments` 使用上面嘅留言種子；讚／笑／留言數可由觀眾估計及固定 seed 產生，屬遊戲論壇模擬值，唔另加固定「幾萬人到場」事實。隊伍支持留言必須對應本屆參賽名單。

實作驗收：完成／爆冷／險勝／同時／延期後開賽／取消／中止／冇場地／冇錢，各分支資料一致；只一篇年度主帖；讀檔唔重發；冠軍唔早過正式決賽結果出現；正常稿唔誤用碰撞圖。

## 12. 實際偏航相撞稿

第二版競渡由航跡模擬提供 `rounds[].incidents`（接觸時間、位置及另一隊 ID）。只有已完成賽事包含實際接觸，年度主帖先改用「【偏航相撞】…碰撞影響部分隊伍成績」標題；正文逐場交代相碰隊名、減速同修正航向，兩艘船記錄同一次接觸時去重。公布時間已包括受阻，唔加額外虛構罰秒，亦唔推論受傷或落水。冇接觸嘅場次沿用正常／險勝／爆冷稿。

即時撞船帖及包含實際碰撞的賽後主帖使用 `UI/news/dragonBoatCollision.webp`（用戶原圖：`UI/news/薩利亞！龍舟激撞現場.png`），另備 180px 列表縮圖。沒有碰撞、取消或沒有場地的報道不使用此圖。
